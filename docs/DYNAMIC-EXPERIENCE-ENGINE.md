# SHELTER DYNAMIC EXPERIENCE ENGINE — Architecture

> **الحالة:** المتطلبات `OWNER APPROVED · HIGH PRIORITY` (M31، 2026-10-01). المعمارية أدناه `DRAFT — PENDING OWNER REVIEW (P04)`.
> **المتطلبات القانونية:** `DX-001…DX-038` في [`SHELTER-WEBSITE-MASTER-REQUIREMENTS.md`](SHELTER-WEBSITE-MASTER-REQUIREMENTS.md) (المجال 45).
> **لا تنفيذ قبل:** بوابات المشروع، ومعمارية الـDashboard (P04)، وقرار المنصة DB-08.

## 1. المبدأ
- **حالتان للموقع:**
  - **عند وجود** حدث، أو مناسبة، أو عرض، أو تكريم، أو لحظة علامة: يتفاعل الموقع **مؤقتًا**.
  - **عند عدم وجود شيء:** يعود **تمامًا** إلى الحالة الطبيعية النظيفة.
- **فصل كامل عن الموقع الأساسي:** المحرك طبقة إضافية لا تمس:
  - الخطوط، والتخطيط، والتنقل.
  - الوصولية، وبنية العلامة.
- **الإدارة:** كله من الـDashboard **بلا كود** (Owner فقط في V1).

**قواعد ثابتة:**
- **`public_employee_profiles` جدول مستقل تمامًا.**
  - لا يحتوي ولا يرتبط بأي بيانات HR: الراتب، والهاتف، والهوية، والحضور، والمستندات.
  - **لا علاقة له بطلبات التوظيف** (`job_applications`).
  - أي ربط داخلي مستقبلي بسجل HR يكون **من جهة HR فقط**، والموقع العام لا يقرؤه.
- **زر النشر لا يعمل** بلا موافقة الموظف المسجلة (G13-TF-01).

## 3. محرك الحل: ماذا يُعرض الآن؟
**الحساب:** على الخادم عند الطلب، بتخزين مؤقت قصير (60 ثانية) يُبطل فورًا عند أي تعديل أو "Disable Now".

**الخطوات:**
1. **الجمع:** كل تجربة تحقق كل الشروط التالية:
   - `starts_at ≤ now < ends_at` (بالـUTC، ويُعرض بالمنطقة الزمنية للسوق).
   - `status ∈ {active, scheduled→active}`.
   - ليست `paused` / `cancelled` / `emergency_disabled`.
   - تطابق الفرع أو اللغة أو الصفحة.
2. **التجاوز اليدوي:**
   - `manual_state = on` يفعّل.
   - `off` يعطّل، بغض النظر عن الوقت.
3. **الترتيب:** حسب `priority`. الافتراضي: Critical/Emergency Notice > Major Event > Campaign > Seasonal Experience > Normal Announcement.
4. **التخصيص لكل موضع:**
   - تجربة **واحدة فقط** لكل Placement (شريط علوي، Hero، Feature، Strip، Modal).
   - **ثيم موسمي واحد فقط** نشط في نفس الوقت.
   - **لا تكديس.**
5. **التعارض:**
   - إذا تنافست تجربتان على نفس الموضع، أو ثيمان موسميان، يظهر **Warning** في الـDashboard (Active Now + عند الحفظ).
   - **الموقع يعرض الأعلى أولوية فقط.**
6. **لا شيء:** **لا يُرسم أي مكون، ولا حاوية فارغة، ولا فراغ.**

**العدّ التنازلي:**
- يُرسل وقت الانتهاء من الخادم (UTC + المنطقة).
- الواجهة تحسب الفرق من **الوقت المصحح بفرق ساعة الخادم**، لا من ساعة الجهاز وحدها.
- ينتهي على الواجهة بإخفاء المكون بلا إعادة تحميل.

## 4. التحميل والأداء
| القاعدة | التنفيذ |
|---|---|
| لا أصول لتجربة غير نشطة | حزمة الثيم (`asset_bundle`) تُحمّل **بـDynamic import فقط إذا** كان الثيم نشطًا. لا CSS ولا JS ولا صور للكريسماس في يوليو |
| ميزانية لكل تجربة | **حد افتراضي:**<br>- ≤ 30KB JS مضغوط + ≤ 150KB وسائط فوق الشاشة الأولى (موبايل).<br>- الثيم الموسمي ≤ 40KB JS.<br>- يُقاس بـLighthouse على الـPreview قبل التفعيل. **يُرفض التفعيل** إذا كسر بوابات LCP/INP/CLS |
| الحركة | Motion (المكتبة الافتراضية). GSAP **فقط** لتأثير لا تحققه Motion أو CSS، مع مبرر موثق، **ولا تُحمّل المكتبتان معًا.**<br>لا Scroll hijack، ولا تحريك كل عنصر، ولا Canvas/WebGL افتراضيًا (الثلج مثلًا CSS خفيف أو صورة متحركة صغيرة) |
| Reduced motion | كل ثيم له `reduced_motion_static`: بديل ثابت بالصورة واللمسات، بلا حركة |
| الموبايل | `mobile_preset` لكل ثيم. حركة الديسكتوب لا تُفترض على الموبايل. الاختبار على مصفوفة المشروع كاملة |
| العزل عند الفشل | كل موضع ديناميكي داخل **حد خطأ** (Error boundary / try-catch على الخادم): أي فشل = لا يُرسم ذلك الموضع فقط، **والرئيسية تكتمل**. فشل قاعدة التجارب = الموقع الطبيعي |
| العودة التامة | الثيم يضيف طبقة `data-experience="theme-id"` على `<html>` وأصولًا منفصلة. عند الانتهاء تُزال الطبقة. **اختبار Visual regression:** لقطة "طبيعي" قبل وبعد = متطابقة |

## 5. الـDashboard — وحدة "التجارب" (Owner فقط)
```
التجارب (Experiences)
├── النشط الآن (Active Now)   — كل ما يؤثر على الموقع + وقت الانتهاء + [أوقف الآن] + تحذيرات التعارض
├── المجدول
├── الفعاليات
├── العروض والحملات
├── الثيمات الموسمية
├── الموظف المثالي
├── SHELTER Family
└── الأرشيف                    (المنتهي يبقى للتاريخ — لا حذف تلقائي)
```

**أوامر لكل تجربة:**
- إنشاء الآن · جدولة لاحقًا · انتهاء تلقائي · تمديد · إيقاف مؤقت · استئناف · إلغاء · **إيقاف طارئ**.

**المعاينة:**
- **الاختيارات:** عربي/إنجليزي × موبايل/ديسكتوب × **تاريخ ووقت محدد** ("أرني الكريسماس يوم 24 ديسمبر").
- **الآلية:** رابط معاينة موقّع يمرر "وقتًا افتراضيًا" للمحرك، ولا يغيّر الموقع الحي.

**اللغة:** لغة صاحب العمل (M30). مثال: "سيظهر هذا الإعلان في أعلى الموقع حتى 23:59 بتوقيت عمّان".

**التدقيق والنسخ:**
- **سجل التدقيق:** إنشاء · تفعيل · تعطيل · جدولة · انتهاء · تمديد · تغيير الوسائط · تغيير الأولوية · تغيير الموظف المثالي.
- **سجل النسخ:** النص · الخصم · التواريخ · الـCTA · الشروط.

## 6. القياس (بلا PII)
| الحدث | المعاملات |
|---|---|
| `announcement_view` / `announcement_click` | `experience_id` · `type` · `placement` |
| `campaign_view` / `campaign_click` | `campaign_id` · `placement` |
| `event_view` / `event_cta_click` | `event_id` · `placement` |
| `seasonal_experience_view` | `theme_id` · `reduced_motion` (`true`/`false`) |

**القواعد:**
- الـView يُرسل **مرة واحدة** لكل ظهور فعلي في الشاشة (IntersectionObserver)، وليس عند التحميل.
- **ممنوع إرسال:** أسماء موظفين، أو أي بيانات شخصية.
- تُضاف للقاموس العام (PO-043).

## 7. الاختبارات المطلوبة (مختصر)
**اختبارات المحرك:**
- **وحدة المحرك:** الأولوية، والتعارض، والتجاوز اليدوي، والإيقاف الطارئ.
- **الانتقال الزمني:** بدء وانتهاء تلقائي عبر منتصف الليل وتغيير التوقيت، بـ`Asia/Amman` ومنطقة أخرى.
- **حالة لا شيء نشط:** لا عنصر في الـDOM.

**اختبارات السلامة:**
- **حقن فشل:** المحرك يرمي خطأ، والرئيسية كاملة.
- **التحميل المشروط:** لا طلبات شبكة لأصول ثيم غير نشط.
- **Visual regression:** طبيعي = طبيعي بعد الانتهاء.

**الجودة على الأجهزة:**
- Reduced motion = بديل ثابت.
- مصفوفة الاستجابة: 20 عرضًا، AR/EN.
- Lighthouse على الـPreview.

**الخصوصية:** لا موظف منشور بلا `is_published` وموافقة. والـAPI العامة لا تُرجع أي حقل HR.
