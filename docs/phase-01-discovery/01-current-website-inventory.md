## 7. تصنيف المعلومات (KEEP / FIX / REMOVE / MISSING / VERIFY)

### KEEP — نحافظ عليه (كقيمة أو أصل، وليس كتصميم)
- الدومين `shelterjo.com` وكل الـ301 على مستوى الـHost (أغلب الروابط الخارجية والـKnowledge Panel تمر عبرها).
- قيمة الـURLs التي تحمل ترتيبًا أو روابط: `/`، `/menu`، `/best-cafes-irbid-2026/`، `/coffee-house-vs-cafe/`، المنيو العربي، `/blog/` — عبر 301 مدروسة.
- **أفكار** المقالات الجيدة (Coffee house vs café، دليل إربد، كيف يعمل الدرايف ثرو، طرق التحضير، أصول الحبوب) — كمواضيع للـKnowledge Hub، والنص يُكتب/يُعتمد من جديد.
- Cloudflare أمام الموقع (الإعدادات تُراجع لاحقًا بموافقتك).
- وجود `llms.txt` كفكرة (يُكتب من جديد للـGEO).

### FIX — يُصلح في البناء الجديد
- العناوين الطويلة والمكررة والوصف المكرر؛ H1 مفقود/مكرر.
- Schema الفروع (عنوان، إحداثيات، ساعات، هاتف لكل فرع).
- الروابط العربية المشفرة → روابط نظيفة + 301.
- تكرار المنيو وصفحة الموقع وتكرار `www`/بدون `www` في الفهرس.
- المنيو كنص دلالي حقيقي وقابل للبحث.
- نموذج التوظيف (تقليل البيانات + موافقة + سياسة خصوصية).
- تصنيفات المدونة والربط الداخلي.
- HSTS، وتحميل السكربتات الخارجية بعد الموافقة (Consent).
- اتساق الاسم والعنوان والهاتف (NAP) عبر Google والأدلة — **بعد** اعتماد البيانات.

### REMOVE — لا يُنقل
- كل بقايا الـDemo (روابط رياضية، Personal Trainer Footer، صور landio).
- أرشيف الكاتب `/author/info/` (يكشف اسم المستخدم) والتصنيف الافتراضي.
- التعليقات والسبام.
- منيو 2024 القديم، ومحتوى "ربيع 2026" الموسمي المنتهي (أرشفة بعد قرارك).
- الخطوط الخمسة الحالية وإضافات الـBuilder.
- الادعاءات غير المثبتة (بعد قرارك): "أفضل"، "أول"، "Leader"، "أكثر من 7 سنوات"، "أقل من 3 دقائق"…

### MISSING — غير موجود ويجب توفيره
- سياسة الخصوصية · الاسم القانوني ورقم السجل · نسخة إنجليزية كاملة · hreflang.
- المنيو الرسمي · صور منتجات وفروع معتمدة · ملفات الشعار الأصلية.
- منطقة Events / Campaigns · FAQ · مسار حجز (إن أردته) · صفحة رعايات (إن أردتها).
- Google Search Console / GA4 / GTM — **غير معروف إن كانت موجودة.**
- بيانات Core Web Vitals وفحص Accessibility (يحتاج فتح الوصول).
- روابط الـ6 مقالات غير المعروفة.
