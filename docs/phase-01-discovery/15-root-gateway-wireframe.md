> **الحالة:** ROOT-01 = D ✅ (D-052) · الهيكل: Header مختصر ✅ (D-066) · العربية أولًا بصريًا بلا IP/Geo Redirect ✅ (D-067) · ترتيب الأقسام ① → ④ (RG-01) لم يُعتمد صراحة بعد (PO-005) · **النصوص = DRAFT ONLY / Placeholder** حتى مرحلة Brand Content، حيث تُعرض 3 خيارات لكل نص (D-068). **لا تنفيذ.**
> **هذا Wireframe هيكلي منخفض الدقة (Lo-fi):** يحدد ترتيب المحتوى ووظيفته فقط. **لا ألوان ولا خطوط ولا تصميم بصري** (الـUI بعد اعتماد الـIA).
> **قاعدة المحتوى:** كل نص هنا **مسودة** مبنية على معلومات معتمدة فقط (الاسم D-007، الفروع D-008/D-020، الساعات D-020، الرقم D-057، التأسيس D-018). أي جملة وصفية أو تسويقية تحتاج اعتمادك قبل النشر.
> **آخر تحديث:** 2026-10-01

## 1. وظيفة الجذر
1. **للزائر:** يصل للمنيو أو الفروع بضغطة واحدة بلغته، بدون تحويل تلقائي (D-052).
2. **لمحركات البحث:** صفحة `x-default` حقيقية فيها تعريف واضح لكيان العلامة. `/ar/` و`/en/` نسخ اللغتين.
3. **للذكاء الاصطناعي:** حقائق واضحة ثابتة في HTML: من نحن، أين، الفروع، كيف نتواصل.
4. **للمستقبل:** عند وجود دولة ثانية يتحول قسم "فروعنا" إلى "اختر دولتك"، بدون تغيير الرابط أو وظيفة الصفحة.

## 4. ما يدخل وما لا يدخل في الجذر

| يدخل | لا يدخل |
|---|---|
| الاسم، تعريف قصير، المنيو والفروع باللغتين، حالة الفرعين، حقائق موجزة، تواصل مختصر | ادعاءات تسويقية ("الأفضل"، "الأول"، أعداد العملاء)، تقييمات، صور غير معتمدة، أسعار، نشرة بريدية، قائمة تنقل كاملة |

**الصور:** مكان اختياري لصورة/فيديو للعلامة في القسم ① **فقط بعد اعتماد أصل من مكتبة الأصول**. الأولوية للسرعة (LCP).

## 5. المواصفات التقنية (للمعلومة — تُنفذ لاحقًا)
- HTML يُولّد على الخادم، ولا يعتمد على JavaScript لعرض المحتوى.
- كل قسم يحمل لغته: `lang="ar" dir="rtl"` أو `lang="en" dir="ltr"`.
- **Canonical** لنفسه.
- **hreflang:** `x-default` → `/` · `ar` → `/ar/` · `en` → `/en/`.
- **Schema:** `Organization` + `WebSite`، مع إشارة للفرعين (`LocalBusiness` / `CafeOrCoffeeShop` تفصيلًا في صفحات الفروع).
- لا تحويل تلقائي، ولا تذكُّر للغة بدون قرارك.
- **أداء:** صفحة خفيفة جدًا بلا مكتبات حركة ثقيلة. الحركة خفيفة جدًا إن وُجدت (Motion System لاحقًا).
