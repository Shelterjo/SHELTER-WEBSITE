# ACCESSIBILITY CHECKLIST — Menu (Phase J)

> **الحالة:** `DRAFT` · **الهدف:** WCAG 2.2 AA · **آخر تحديث:** 2026-10-01
> كل بند يُختبر يدويًا في الـPrototype والإنتاج: VoiceOver (iOS) · TalkBack (Android) · NVDA (Windows) · كيبورد فقط · تكبير 200%.

## الاتجاه واللغة (RTL / LTR)
- [ ] `<html lang="ar" dir="rtl">` و`<html lang="en" dir="ltr">`.
- [ ] الاسم الإنجليزي في الصفحة العربية `lang="en"`، والعربي في الإنجليزية `lang="ar"`.
- [ ] الأسماء المختلطة (V60 كولومبيا، "(بدون سكر)"، "+") والأسعار داخل `<bdi>`. لا انقلاب للرموز.
- [ ] الأسهم والأيقونات الاتجاهية تنعكس، والبحث والإغلاق لا ينعكسان.
- [ ] تدرّج حافة الشريط الأفقي يتبع الاتجاه.
- [ ] ترتيب التركيز يتبع ترتيب القراءة في الاتجاهين.

## الكيبورد
- [ ] كل عنصر تفاعلي يصل بـTab بترتيب منطقي: بحث ← فرع ← موسم ← شريط الفئات ← الأقسام.
- [ ] رابط "تخطَّ إلى المنيو" أول عنصر.
- [ ] **شريط الفئات:** الأزرار روابط عادية. أي زر يصبح ظاهرًا عند التركيز عليه داخل الشريط الأفقي.
- [ ] **محدد الفرع:** Tab للمجموعة، وEnter أو Space للتفعيل.
- [ ] **البطاقة:** Enter يفتح التفاصيل.
- [ ] **التفاصيل:** `Esc` يغلق، والتركيز محبوس داخلها ويعود للبطاقة.
- [ ] **الاقتراحات:** الأسهم تتنقل، وEnter يختار، و`Esc` يغلق (Combobox pattern).
- [ ] لا مصيدة تركيز خارج النوافذ.

## التركيز المرئي
- [ ] إطار تركيز واضح (2–3px، تباين ≥ 3:1) على كل العناصر، ولا يُزال.
- [ ] العنصر المركّز لا يختفي تحت الأشرطة اللاصقة (`scroll-padding-top: 112px`).

## قارئ الشاشة
- [ ] **العناوين:** H1 المنيو ← H2 الفئة والموسم ← H3 القسم الفرعي.
- [ ] الأصناف قائمة (`list`/`listitem`)، والبطاقة تُقرأ: الاسم، الاسم الثاني، السعر بالعملة الكاملة، الحالة إن وُجدت.
- [ ] **السعر:** "3.50 دينار أردني" / "3.50 Jordanian dinars". الرمز "د.أ" له نص مقروء.
- [ ] **ALL CAPS:** أسماء مثل MESTEKH وV60 HONDURAS LAS تُقرأ ككلمات لا حروف. وإلا `aria-label` بحالة عادية من الـCMS.
- [ ] **الزر النشط:** في شريط الفئات `aria-current="true"`، وفي محدد الفرع `aria-pressed`.
- [ ] **الأزرار بأيقونة فقط** (بحث مضغوط، كل الفئات، إغلاق) لها `aria-label` باللغتين.

## إعلانات البحث
- [ ] الحقل له `<label>` ظاهر، وليس Placeholder فقط.
- [ ] "N نتيجة" في `aria-live="polite"`، وتُعلن بعد توقف الكتابة وليس مع كل حرف.
- [ ] "لا توجد نتائج" تُعلن، وزر المسح مقروء ("مسح البحث").
- [ ] **بعد القفز لصنف:** يذهب التركيز للبطاقة ويُعلن اسمها. الإبراز البصري ليس الإشارة الوحيدة.

## Bottom Sheet / Modal
- [ ] `role="dialog"` + `aria-modal="true"` + `aria-labelledby` (اسم الصنف).
- [ ] التركيز عند الفتح على العنوان، ويعود للبطاقة عند الإغلاق.
- [ ] **الإغلاق:** زر ظاهر 44px، و`Esc`، وBack. **السحب ليس الطريقة الوحيدة.**
- [ ] المحتوى خلف النافذة `inert`، ولا يُقرأ أثناءها.
- [ ] الخلفية المعتمة 40–60% (يُثبت في الـVisual).

## التباين (يُثبت في مرحلة الـVisual مع ألوان العلامة)
- [ ] النص العادي ≥ 4.5:1، والكبير ≥ 3:1، والأيقونات والإطارات ≥ 3:1.
- [ ] البطاقة الخافتة ("غير متوفر") **يبقى نصها ≥ 4.5:1.** الخفوت للصورة والإطار فقط.
- [ ] الوضع الداكن (إن وُجد) يُختبر بشكل مستقل.

## الصور
- [ ] **في البطاقة** الصورة زخرفية (`alt=""`) لأن الاسم بجانبها، فلا يُقرأ الاسم مرتين.
- [ ] **في التفاصيل** `alt` معتمد من الـCMS (`alt_ar` / `alt_en`) يصف الصنف، أو `alt=""` إذا لم يُعتمد.
- [ ] لا نص داخل الصور.

## الشارات والحالات
- [ ] "جديد" و"موسمي" و"غير متوفر حاليًا" و"متوفر في DRIVE فقط" نص مقروء، وليست ألوانًا أو أيقونات فقط.
- [ ] **حالة الفرع** نص ("مفتوح الآن — حتى 2:00 ص") + رمز شكلي، والدائرة زخرفية (`aria-hidden`).
- [ ] **تحديث الحالة كل دقيقة لا يُعلن تلقائيًا** (حتى لا يزعج). يُقرأ عند الوصول إليه.

## اللمس والتخطيط
- [ ] كل هدف ≥ 44×44px، ومسافة ≥ 8px. **مُقاس:** 0 أهداف أقل بعد الإصلاح (`UX-VALIDATION` R-06).
- [ ] لا تجاوز أفقي للصفحة على 320px. **مُقاس:** لا تجاوز.
- [ ] تكبير النص 200% وتكبير المتصفح 400% (Reflow) بلا فقدان محتوى. الأسماء تلتف ولا تُقص.
- [ ] لا يُمنع التكبير (`user-scalable` غير معطّل).
- [ ] الاتجاه الأفقي (Landscape) يعمل.

## الحركة
- [ ] `prefers-reduced-motion`: لا تمرير ناعم، ولا حركة للنوافذ (ظهور فوري)، ولا إبراز متحرك.
- [ ] لا وميض، ولا حركة تلقائية مستمرة.
