# Low-Fi Wireframes — Menu

> **LOW-FI:** تخطيط وسلوك فقط. لا ألوان، ولا خطوط، ولا شكل نهائي.
>
> **البيانات:** المنيو الحقيقية (191 صنفًا) من Inventory v1.0.
>
> **التعليم داخل الـWireframes:**
> - **الصور:** مربعات رمادية، لأنه لا توجد صور معتمدة بعد.
> - **أسماء عربية بخط منقط:** أسماء من المصدر بانتظار الاعتماد (D-137).
> - **"مثال":** حالة توضيحية وليست بيانات حقيقية، لأن التوفر `UNKNOWN`.
> - **الأوقات:** محاكاة لعرض حالات الفرع.
>
> **التصفح:**
> - المصدر HTML: [`html/`](html/)، ويمكن فتحه في أي متصفح وتجربة العروض.
> - طريقة التوليد: [`tools/`](tools/).
