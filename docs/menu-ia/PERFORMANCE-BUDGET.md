# PERFORMANCE BUDGET — Menu (Phase H)

> **الحالة:** `DRAFT — PENDING OWNER APPROVAL` · **آخر تحديث:** 2026-10-01
> **المبدأ:** النص والأسعار أولًا، والصور بعدها، والأدوات الخارجية آخرًا.
> الأرقام أهداف مبررة، وليست وعودًا. المنصة لم تُختر بعد (DB-08)، فالميزانية بأحجام النقل المضغوطة ومؤشرات Core Web Vitals.

## 1. ما قسناه فعلًا (Wireframe ببيانات المنيو الكاملة)

| العنصر | خام | مضغوط (gzip) | ملاحظة |
|---|---|---|---|
| Markup كل الأصناف الـ191 بالاسمين والسعر | 58KB | **6.5KB** | بلا CSS |
| فهرس البحث (الأسماء المعروضة والمصدرية، الفئة، السعر) | 20.5KB | **4.1KB** | يُضمّن في الصفحة |
| `Menu` JSON-LD (الاسم والسعر لكل صنف) | 23.5KB | **1.6KB** | |

**تقدير الإنتاج:** + `srcset` لـ191 صورة (حوالي 300 بايت لكل صورة) + Classes ← **HTML حوالي 20–25KB مضغوطًا.**

## 2. الميزانية

| البند | الهدف | التبرير |
|---|---|---|
| **HTML (لكل لغة)** | ≤ **35KB** مضغوطًا | تقدير الإنتاج 20–25KB + هامش |
| **CSS** | ≤ **25KB** مضغوطًا · الحرج Inline ≤ 14KB | 14KB = أول رحلة شبكة (TCP initial window) |
| **JS خاص بالمنيو** | ≤ **30KB** مضغوطًا: البحث + التفاصيل + الزر النشط + حالة الفرع + الـHistory | منطق صغير، والبيانات في الـHTML |
| **JS الإجمالي في الصفحة** (مع إطار العمل) | ≤ **100KB** مضغوطًا | الأطر الحديثة 40–90KB. **المحتوى لا ينتظر الـJS** (SSR/SSG)، والتفعيل على أجزاء (Islands) أو مؤجل |
| **الخطوط** | ≤ **120KB** WOFF2 · عائلتان كحد أقصى · 3–4 ملفات · Subset | الخطوط العربية كبيرة (60–150KB بلا Subset) |
| | `font-display: swap` · Preload لملف واحد (خط النص بلغة الصفحة) · مقاسات بديلة (`size-adjust`) | منع النص المخفي والقفز (CLS) |
| **صور الشاشة الأولى** | ≤ **6 صور** تُحمّل فورًا · ≤ **60KB** مجموعًا | مع قسم الموسم: 5 مصغرات 64px ← 128px@2x حوالي 5–8KB AVIF |
| **صورة البطاقة** | AVIF (WebP بديل) · `srcset` 240 / 360 / 480w · حوالي 12–25KB | البطاقة 158–237px × كثافة شاشة 2 |
| **`sizes` للبطاقة** | `(max-width:359px) 96px, (max-width:599px) 50vw, (max-width:1199px) 33vw, 240px` | المتصفح يختار أصغر ملف مناسب |
| **الصور تحت الشاشة الأولى** | `loading="lazy"` + `decoding="async"` + أبعاد محجوزة (`width` و`height` أو `aspect-ratio`) | CLS = 0 من الصور |
| **الأقسام البعيدة** | `content-visibility: auto` + `contain-intrinsic-size` | رسم أسرع لـ191 بطاقة **دون حذفها من الـHTML**، أي بدون Virtualization |
| **الأدوات الخارجية** | GTM/GA4 **بعد** `load` + Idle (حوالي ثانيتين)، أو أول تفاعل · Consent Mode v2 | لا تؤخر أول محتوى مفيد |
| | **ممنوع في صفحة المنيو:** HubSpot · Chat · خرائط Google · YouTube · خطوط من Google مباشرة | أي واحدة منها تضيف 100–500KB JS |
| **الحركة** | `transform` / `opacity` فقط. **Motion** مسموح للـSheet/Modal (قرار الأدوات من الـOwner) **بتحميل Lazy عند أول فتح**، خارج المسار الحرج وضمن ميزانية JS المنيو. إذا تجاوز الميزانية أو أثّر على INP ← CSS Transitions | لا Jank ولا تأخير في التفاعل (INP). الأداء يتقدم على الحركة الزخرفية |

## 3. Core Web Vitals

| المؤشر | الهدف (الحقل، p75 موبايل) | المختبر |
|---|---|---|
| **LCP** | ≤ **2.5s** | ≤ 2.5s على Slow 4G + معالج أبطأ 4× |
| **INP** | ≤ **200ms** | البحث: النتائج خلال ≤ 50ms لكل حرف (191 صنفًا في الذاكرة) · فتح التفاصيل: أول إطار ≤ 100ms |
| **CLS** | ≤ **0.1** | أبعاد محجوزة للصور، والخطوط بمقاسات بديلة، ولا عناصر تُحقن فوق المحتوى |
| TBT (مختبر) | ≤ 200ms | |
| Lighthouse Performance (موبايل) | ≥ 90 | |

**عنصر الـLCP المتوقع:**
- **بلا صور (الإطلاق):** نص (H1 أو أول بطاقة)، وهذا سريع.
- **مع الصور:** أول صورة في الموسم أو أول بطاقة، فلا تكون Lazy.

## 4. طريقة القياس (بعد بدء البناء — ليس الآن)
1. **Lighthouse CI** على كل نسخة Preview:
   - **الأجهزة:** موبايل بـSlow 4G + معالج 4×.
   - **الصفحات:** العربية والإنجليزية، مع `?branch=drive` وبدونه.
2. **WebPageTest:** هاتف متوسط على 4G من منطقة قريبة.
3. **ميزانية في الـCI:** الحجم المضغوط لـHTML وCSS وJS والخطوط، **ويفشل البناء إذا تجاوزها.**
4. **بعد الإطلاق:** بيانات الحقل من Search Console وCrUX (`docs/google`).
