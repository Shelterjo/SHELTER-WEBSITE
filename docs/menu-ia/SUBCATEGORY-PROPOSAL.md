> - `PENDING`: لا نصنّف.

## قرارات مطلوبة منك (P-04)

1. **أسماء الأقسام الفرعية الـ12** (عربي وإنجليزي): اعتماد أو تعديل.
2. **الأصناف بثقة MEDIUM (25):** اعتماد كمجموعة، مع ذكر الاستثناءات فقط.

   - CODE RED: مشروب طاقة أم مشروب غازي؟

## اقتراح اختياري (P2، ليس مطلوبًا الآن)
- **SMOOTHIES (23) وMILKSHAKE (21)** طويلتان بلا أقسام فرعية: حوالي 4–5 شاشات مع الصور.
- **تقسيم ممكن لاحقًا بالاسم فقط:** SMOOTHIES إلى "فاكهة واحدة" و"خلطات".
- **لم يُطبّق**، لأن الموجز حصر الأقسام الفرعية في HOT وCOLD وFIZZY.
