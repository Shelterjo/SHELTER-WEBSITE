# CACHE-CDN — الـCache والـCDN والإبطال الذكي وحداثة البيانات

| البند | القيمة |
|---|---|
| **الغرض** | موقع سريع خلف Cloudflare **بلا بيانات أعمال قديمة**: إبطال انتقائي بالوسوم لكل كيان، وحالة زمنية تُحسب من الخادم، ولا Purge شامل |
| **الحالة** | `SPEC — READY FOR BUILD` · التنفيذ: `NOT STARTED` |
| **مرحلة البناء (M36 §6)** | **PHASE 1** (Master Data ← مفردات الوسوم) ← **PHASE 2** (ترويسات الـCache وCache التطبيق) ← **PHASE 5** (ربط Cloudflare). خطة المشروع: P08 · P09 |
| **المتطلبات** | M35 §22 · §23 · §24 · §25 · PERF-023 · CF-003 · CF-004 · CF-005 · CF-008 · CF-009 · PO-013 · G14-TF-08 · L-5 · FINAL-ARCHITECTURE-REVIEW §13 · PLATFORM-ARCHITECTURE §4.2–§4.3 |
| **المراجع الملزمة** | [`PLATFORM-ARCHITECTURE`](../architecture/PLATFORM-ARCHITECTURE.md) · [`ADR-001`](../adr/ADR-001-platform.md) (الـCDN) · [`MASTER-DATA-HUB`](../MASTER-DATA-HUB.md) · [`DEPLOYMENT`](DEPLOYMENT.md) · [`ROLLBACK`](ROLLBACK.md) |

> **المصدر الوحيد** = Master Data وContent Graph في قاعدة البيانات. كل طبقة Cache **نسخة مؤقتة** منه فقط.
> لا يُنفذ من هنا أي تغيير على Cloudflare أو Cloudways: كل إعداد مقترح أدناه يُعرض أولًا ويُطبق بعد موافقتك (CF-003).

## 1. الطبقات
| الطبقة | الدور | القرار |
|---|---|---|
| **المتصفح** | HTML يُعاد التحقق منه دائمًا · الأصول ثابتة | `Cache-Control` من التطبيق |
| **Cloudflare (Edge)** | الطبقة الأساسية للسرعة | يحترم ترويسات التطبيق (`s-maxage`). قاعدة Cache تجعل HTML العام قابلًا للتخزين، وقاعدة Bypass للـDashboard والـAPI |
| **Cloudways Varnish** | طبقة ثالثة غير ضرورية | **تُعطَّل لتطبيق Laravel** (يُتحقق في الـAudit — A-03). طبقتان تكفيان |
| **Laravel** | Cache الاستجابات العامة + Cache قراءات Master Data | §6 |
| **قاعدة البيانات** | **المصدر** | — |

## 2. السياسة لكل نوع استجابة (قيم تقنية افتراضية قابلة للتعديل)
| النوع | المتصفح | Cloudflare | ملاحظة |
|---|---|---|---|
| HTML عام (`/ar/…` · `/en/…` · `/`) | `max-age=0, must-revalidate` | `s-maxage` ≤ **300 ثانية**، ومحدود بالحالة الزمنية (§4). **الصفحات ذات الطبقة الديناميكية (`dx`): ≤ 60 ثانية**، ليظهر Safe Mode خلال دقيقة حتى بلا توكن إبطال ([`SAFE-MODE`](SAFE-MODE.md)) | وسوم `Cache-Tag` |
| صفحات فيها نماذج (التواصل، التوظيف، الشراكات) | `private, no-store` | **Bypass** | رمز CSRF مرتبط بالجلسة: تخزينه يكسر النموذج |
| `/dashboard/*` · `/api/*` الداخلي · `/health` | `private, no-store` | **Bypass** | ولا تُخزن أي استجابة فيها Cookie جلسة |
| أصول Vite (`/build/*`، اسم بالـHash) | `max-age=31536000, immutable` | نفس القيمة | تغيير الملف = اسم جديد، **بلا Purge** |
| الصور (`/media/*`، اسم بالـHash) · الخطوط | `max-age=31536000, immutable` | نفس القيمة | الصفحة التي تستخدم الصورة تُبطَل بوسمها |
| API قراءة عام (إن وُجد، مثل فهرس البحث) | قصير | `s-maxage=60` أو ملف بالـHash | وسم `search:{locale}` |
| `robots.txt` · `sitemap.xml` · `llms.txt` | قصير | `s-maxage=3600` | وسوم `robots` · `sitemap` تُبطَل عند النشر |
| تحويلات 301 | يخزنها المتصفح دائمًا | `s-maxage=3600` | لذلك **301 للدائم فقط** ([`LEGACY-URL-MIGRATION`](LEGACY-URL-MIGRATION.md)) |
| 404 | `no-cache` | `s-maxage=60` | صفحة تُنشر حديثًا تظهر سريعًا |
| 5xx | `no-store` | لا تخزين | — |

**قاعدة الـMiddleware:** المسارات العامة القابلة للتخزين تعمل بمجموعة Middleware **بلا Session ولا Cookies ولا CSRF**. أي استجابة فيها `Set-Cookie` لا تُخزن.

## 3. مفردات الوسوم (Cache tags)
| الوسم | يُضاف إلى | مثال |
|---|---|---|
| `menu:{locale}` | صفحة المنيو بلغة | `menu:ar` · `menu:en` |
| `prd:{PRD-ID}` · `cat:{CAT-ID}` | أي صفحة تعرض المنتج أو الفئة خارج المنيو (مثل الرئيسية) | `prd:PRD-00014` |
| `branch:{code}` · `hours:{code}` | بطاقات الفروع وصفحاتها والـFooter | `branch:BR-DRIVE` · `hours:BR-HOUSE` |
| `global:{group}` | القيم المركزية (التواصل، السوشال، الـFooter) | `global:contact` |
| `page:{id}` · `media:{id}` | صفحة من `pages` · صورة مستخدمة | — |
| `dx` · `exp:{id}` | أي صفحة فيها طبقة ديناميكية · تجربة محددة | — |
| `schema:{type}` | JSON-LD | `schema:menu` · `schema:org` |
| `search:{locale}` · `sitemap` · `robots` · `redirects` | الملفات المشتقة | — |

- **الصفحة تعلن وسومًا قليلة وعامة**، و**المحلّل** (§5) يحوّل تغيير الكيان إلى الوسوم الصحيحة. هكذا تبقى الترويسة صغيرة.
- **مثال M35 §23:** تغيير سعر CAPPUCCINO (`PRD-00014`) يُبطل فقط:
  `prd:PRD-00014` · `menu:ar` · `menu:en` · `schema:menu` · `search:ar` · `search:en`.
  صفحات "من نحن" والفروع **لا تُلمس**.

## 4. البيانات الحساسة للوقت (M35 §24)
**البيانات:** السعر · التوفر · الساعات المنتظمة · الساعات الخاصة · الإغلاق · الحملات · الفعاليات.
1. **الحالة الزمنية تُحسب عند الطلب في الخادم** بتوقيت السوق (`markets`: Asia/Amman)، ولا تعتمد على JavaScript العميل ولا على المجدول وحده (PLATFORM-ARCHITECTURE §4.3).
2. **مدة التخزين لا تتجاوز أقرب تغيّر حالة:**
   `s-maxage = min(300، الثواني حتى أقرب تغيّر)`.
   - مصادر "أقرب تغيّر": `branch_hours` · `hours_exceptions` · `experiences` (البداية والنهاية) · النشر المجدول.
   - مثال: فرع يغلق بعد 40 ثانية ← الصفحة تُخزن 40 ثانية فقط.
3. **إبطال فوري عند النشر** بالوسوم (§5).
4. **المجدول شبكة أمان ثانية:** يبطل الوسوم عند الحدود الزمنية، لكن صحة العرض **لا تعتمد عليه**.

## 5. خدمة الإبطال وتدفق المزامنة (M35 §25)
الإبطال = **محوّل قناة "Website"** داخل `app/Services/Channels/` (FINAL-ARCHITECTURE-REVIEW §12)، ويستخدم نفس طابور المزامنة. **لا نظام ثانٍ.**
**المحلّل** = نفس خريطة الأثر في [`CHANGE-IMPACT`](CHANGE-IMPACT.md) §2: ما تعرضه المعاينة هو بالضبط ما يُبطَل.
```
الـOwner يعدّل ← Publish Guard ← نشر: content_versions + audit_logs
  ← المحلّل (نفس خريطة CHANGE-IMPACT): الكيان والحقول المتغيرة ← قائمة وسوم
  ← sync_jobs (channel = website):
       1. Laravel: زيادة عدّاد إصدار كل وسم
       2. Cloudflare: Purge بالوسوم (أو بالروابط كبديل — §7)
       3. تسخين الروابط الأساسية المتأثرة
       4. تحقق: ترويسة X-Content-Rev في الاستجابة = المراجعة الجديدة
  ← channel_sync_states (الكيان، website) = SYNCED أو FAILED
  ← بالتوازي: القنوات الأخرى (Schema مشتق، GBP بمحوّله الخاص)
  ← فشل بعد 5 محاولات (1 ← 5 ← 30 دقيقة ← 6 ساعات) ← signals: ISSUE · HIGH
```
- **Safe Mode** (G14-TF-08): تفعيله يبطل الوسم `dx` فورًا في التطبيق وفي Cloudflare.
- **بعد النشر أو التراجع:** مفاتيح Cache التطبيق تحمل `release_id`. Cloudflare: إبطال **بالوسوم المتأثرة فقط**. إصدار يغير القوالب عامةً يعتمد على مدة HTML القصيرة (≤ 5 دقائق)، والأصول القديمة تبقى متاحة 7 أيام لأن HTML المخزن قد يشير إليها.

## 6. Cache التطبيق في Laravel
- **مفتاح الاستجابة:** `release_id` + اللغة + المسار + المعاملات الوظيفية فقط + **أرقام إصدار وسوم الصفحة**.
  - معاملات التتبع (`utm_*` وأمثالها) لا تدخل المفتاح.
  - **الإبطال = زيادة رقم إصدار الوسم.** لا حاجة لدعم Tags في مخزن الـCache، فيعمل على `database` أو `redis`.
- **Cache القراءات:** المنيو المجمّع لكل لغة، والفروع، والقيم المركزية، بنفس نمط المفاتيح.
- ترويسة تشخيص `X-Cache: HIT-APP | MISS` (تُخفى عن الـOwner).
- لا Cache لأي استجابة فيها بيانات Owner أو جلسة أو PII.

## 7. Cloudflare: القدرات والصلاحيات (PO-013)
| البند | الحالة |
|---|---|
| الإبطال بالوسوم (Purge by Cache-Tag) في خطة حسابكم | ⏳ **يُتحقق من الخطة (PO-013)** |
| حدود الإبطال (عدد الوسوم أو الروابط لكل طلب، والمعدل) وحجم ترويسة `Cache-Tag` | ⏳ يُتحقق |
| قواعد Cache وPage Rules الحالية للموقع القديم وأثرها عند الانتقال | ⏳ Audit (CF-004) |
| **البديل إن لم يتوفر الإبطال بالوسوم** | Purge **بالروابط**: المحلّل يحوّل الوسوم إلى روابط من مولّد المسارات، على دفعات حسب الحد |

- **التوكن:** API Token بصلاحية **Cache Purge فقط**، ومحدود بزون `shelterjo.com` (CF-009). توكن قراءة منفصل لـSite Health عند الحاجة (CF-008).
- **ممنوع Global API Key.** التوكن في `.env` الإنتاج فقط، ومسجل في `integrations` (النطاق، الانتهاء، الحالة) **بلا القيمة**.
- **ممنوع "Purge Everything"** من الكود (فحص آلي يمنع ظهوره).

## 9. البيانات
`content_versions` · `audit_logs` · `sync_jobs` · `channel_sync_states` · `signals` · `integrations` · `feature_flags` · `markets` · `branch_hours` · `hours_exceptions` · `experiences`. **لا جداول جديدة:** عدّادات الوسوم في مخزن الـCache نفسه.

## 10. مكانه في الـDashboard
- **الـOwner لا يرى كلمة "Cache".** بعد النشر يرى: "تم النشر — الموقع محدّث ✓"، أو "تم النشر، وتحديث الموقع متأخر — نعيد المحاولة تلقائيًا" (من `channel_sync_states`).
- **الجودة ← صحة الموقع ← التكاملات ← Cloudflare:** حالة التوكن وآخر إبطال ناجح.
- أي فشل يظهر في **يحتاج انتباه**.

## 12. ما لا يُفعل
- لا Purge شامل، ولا Global API Key.
- لا تخزين للـDashboard أو النماذج أو أي بيانات شخصية.
- لا حالة زمنية تعتمد على JavaScript العميل أو المجدول وحده.
- لا Varnish إضافي، ولا Service Worker (P2).
- لا تغيير على Cloudflare أو Cloudways قبل الـAudit وموافقتك.
