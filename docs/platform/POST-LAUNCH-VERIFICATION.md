## 1. T+1h — هل الموقع يعمل؟
| # | الفحص | المصدر | المقبول |
|---|---|---|---|
| H1 | **التوفر** | مراقب خارجي (إن اعتُمد I-12) + `/health` ([`MONITORING`](MONITORING.md)) | يعمل، والاستجابة طبيعية |
| H2 | **أخطاء الخادم** | سجل أخطاء التطبيق · Error Center | لا ارتفاع في 5xx |
| H3 | **أخطاء الواجهة** | Error Center (JS، بلا PII) | لا أخطاء جديدة متكررة |
| H4 | **النماذج** | إشارات `form:{name}:save_failed` = صفر ([`MONITORING`](MONITORING.md) #7) + إرسال حقيقي واحد بعنوان "اختبار إطلاق" **بعلمك**، ثم يُؤرشف (لا حذف) | حفظ ← تأكيد ← نجاح، والرقم المرجعي صحيح |
| H5 | **التحويلات** | عينة من الخريطة (الأعلى قيمة + `/menu` + نسخ http وبدون www) | قفزة واحدة ← 200 |
| H6 | **404** | سجل 404 | لا رابط قديم ذو قيمة يعطي 404 |
| H7 | **الـCache** | ترويسات `cf-cache-status` و`Age` | HTML العام يُخزن ضمن مدته · الـDashboard والنماذج `BYPASS` · لا بيانات قديمة |
| H8 | **الحالة الزمنية** | الفروع والحملات النشطة | "مفتوح الآن" والحملات صحيحة بتوقيت الأردن |
| H9 | **الـDashboard** | دخول الـOwner (هاتف + ديسكتوب) | يعمل، و"يحتاج انتباه" بلا CRITICAL |
| H10 | **Staging** | طلب بلا مصادقة | `401` + noindex |
| H11 | **GA4** | Realtime / DebugView | الأحداث تصل، **بلا تكرار** |

**أي فشل في H1 أو H2 أو H4 = P0** ← قرار التراجع حسب [`ROLLBACK`](ROLLBACK.md) §2.

## 4. عند هبوط الزيارات (MON-012، السياسة §55)
**لا افتراض للسبب.** الفحص بالترتيب:
Redirects ← Indexing ← Canonicals ← robots.txt ← Sitemap ← hreflang ← Server errors ← Page performance ← Tracking errors.
ثم **تشخيص مكتوب** يُعرض عليك قبل أي إجراء.

## 5. قالب التقرير للـOwner
```
تقرير التحقق بعد الإطلاق — T+___   ·   الإصدار: ……   ·   التاريخ: ……
الخلاصة: ✅ الموقع يعمل بشكل سليم  |  ⚠️ يعمل مع ملاحظات  |  🔴 مشكلة تحتاج قرارك

ما الذي يعمل؟
  • الموقع متاح طوال الفترة · النماذج تحفظ الطلبات · التحويلات القديمة تعمل
ما الذي يحتاج انتباهًا؟ (بلغة بسيطة، مع الأثر)
  • مثال: "3 روابط قديمة تصل لصفحة غير موجودة — نقترح توجيهها إلى صفحة المنيو"
هل تحتاج أن تقرر شيئًا؟
  • لا  /  نعم: …… [وافق] [ارفض]
الأرقام (مختصرة): التوفر · أخطاء الخادم · طلبات النماذج · استخدام التحويلات · حالة الـSitemap · Web Vitals (إن كفت العينة)
▸ تفاصيل متقدمة: الفحوص H/D/W كاملة مع الأدلة
```
- التقرير يُحفظ في `audit_logs` ويظهر في **الإشعارات** (الأولوية: Important، أو Critical عند مشكلة).
