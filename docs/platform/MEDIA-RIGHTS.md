## 1. المبدأ: مكتبة واحدة
- **المصدر الوحيد:** `media` + `media_usages` (PLATFORM-ARCHITECTURE §3.3). **لا مكتبة ثانية ولا جدول حقوق منفصل** (M32 §47).
- `docs/governance/APPROVED-ASSET-LIBRARY.md` (`AST-###`) و`media/manifest.json` (`MED-#####`) = **بذرة** تُستورد مرة واحدة (توحيد المعرّفين) ثم تُجمّد (G14-CF-11).
- اليوم: **0 أصول معتمدة** (MEDIA-001). لا شيء يُنشر حتى يعتمد الـOwner كل أصل منفردًا.

## 2. الحقول في `media`
| الحقل (M32 §18) | العمود | القيم |
|---|---|---|
| Photographer | `photographer` | نص (CONFIDENTIAL إن كان اسم شخص) |
| Source | `source` | تصوير SHELTER · مصور خارجي بعقد · مقدم من شريك · أخرى (خيارات الـWireframe `d-media`). **Stock · AI · Google · الموقع القديم = ممنوعة تلقائيًا** (MEDIA-005) وتحتاج اعتمادًا صريحًا للأصل نفسه |
| Rights holder | `rights_holder` | من يملك الحق |
| Usage rights / License | `license` | استخدام كامل · الموقع فقط · محدود بفترة · أخرى (نص) |
| Approval | `approval_status` | `PENDING OWNER APPROVAL` (افتراضي، MEDIA-003) · `APPROVED` · `REJECTED` · `ARCHIVED` |
| Approval date | `approved_at` · `approved_by` | يُملأ آليًا عند الاعتماد |
| People consent status | `people_consent` | `none` (لا أشخاص) · `recorded` · `not_recorded` |
| People consents | `people_consents` (JSON لكل شخص) | المعرّف/الاسم · تاريخ الموافقة · النطاق (Website / Ads / Social) · **مرجع المستند** (أين يُحفظ الورق — لا رفع في V1) · `withdrawn_at` |
| Approved for website? | `ok_website` | نعم / لا |
| Approved for ads? | `ok_ads` | نعم / لا |
| Restrictions | `restrictions` | نص (مثل: لا طباعة) |
| Expiry | `rights_expires_at` | فارغ = لا ينتهي |

**الأولوية القصوى لصور الأشخاص:** الموظفون · العملاء · الفعاليات · SHELTER Family · الموظف المثالي (M32 §18).

تبقى حقول MEDIA-006/008/012: النص البديل AR/EN · نقطة التركيز · الأبعاد · الحجم · `sha256` (منع التكرار) · النسخ AVIF/WebP · تاريخ النسخ.

## 3. قاعدة النشر (دالة واحدة `MediaRights::canUse($media, $usage)`)
يُسمح بالاستخدام **فقط** إذا تحققت كلها:
1. `approval_status = APPROVED`.
2. النطاق مسموح: `ok_website` للموقع، و`ok_ads` للإعلانات.
3. `rights_expires_at` فارغ أو في المستقبل.
4. `people_consent = none`، أو `recorded` لكل شخص **بنطاق الاستخدام** وبلا `withdrawn_at`.
5. المصدر ليس Stock/AI/Google/الموقع القديم، إلا باعتماد صريح لهذا الأصل.

**أين تُفرض (نفس الدالة):**
- **[`PUBLISH-GUARD`](PUBLISH-GUARD.md):** أي مخالفة = **BLOCKING** غير قابل للتجاوز (G14-CF-13). حقوق تنتهي خلال 14 يومًا = WARNING (G-24).
- **العرض من الخادم:** أصل غير صالح لا يُعرض. المكوّن يختفي برفق (لا حالة فارغة — DX-012).
- **خط الصور:** لا اشتقاق إلا للمعتمد (MEDIA-011).
- **صور Google ليست أصولًا معتمدة** (MEDIA-004)، ولا تُسحب آليًا.

## 4. الانتهاء والسحب ← إشارات
| الحدث | الإجراء |
|---|---|
| 14 يومًا قبل `rights_expires_at` | إشارة `ACTION_REQUIRED` بشدة HIGH: "حقوق صورة تنتهي قريبًا — مستخدمة في N أماكن" |
| الانتهاء والأصل ما زال مستخدمًا | إشارة **CRITICAL** + منع أي استخدام جديد. الإخفاء الآلي **خيار في الإعدادات** (G14-TF-09) |
| سحب موافقة شخص | **إلغاء نشر فوري** للأصل في كل مواضعه + إبطال Cache بالوسوم + `audit_logs` (OPS-034، DX-005) |

## 5. Press / Media Kit (P1)
- **الجمهور (M32 §17):** الصحفي · منظم الفعاليات · الشريك · المدوّن · الإعلام — ليصلوا إلى معلومات صحيحة ومعتمدة.
- **مجموعة منتقاة، لا نسخة:** صفحة في `pages` (الرابط في IA الموقع — PO-004) أقسامها تشير إلى `media` و`facts` عبر `media_usages`. **لا مكتبة ثانية ولا مصدر حقائق ثانٍ.**
- **العناصر (M32 §17) وحالتها اليوم:**

| العنصر | المصدر | الحالة اليوم |
|---|---|---|
| الاسم الرسمي · الاسم العربي | `facts` | APPROVED (D-007) |
| سنة التأسيس 2019 | `facts` | APPROVED (D-018) |
| قصة العلامة | `facts` / `pages` | `MISSING — OWNER INPUT REQUIRED` (PO-017) |
| الشعار المعتمد | `media` | `MISSING` حتى ملفات الهوية (M-10، PO-002) |
| صور معتمدة للصحافة | `media` (APPROVED + `ok_website`) | لا أصول معتمدة بعد |
| حقائق الفروع | `branches` · `facts` | المعتمد فقط |
| أبرز الجوائز | `facts` | `PENDING VERIFICATION` (PO-032) |
| جهة التواصل الإعلامي | `contact_points` | `MISSING — OWNER INPUT REQUIRED` (G14-PO-01). **لا بريد مخترع** |

- **غير المعتمد لا يظهر** (لا Placeholders على Production). **لا إرشادات العلامة الداخلية للعامة.**
- الصفحة غير منشورة وخارج الـSitemap حتى اعتماد محتواها (G14-TF-16). تنزيل الشعار للعامة = قرار ضمن G14-PO-01.

## 6. اللوحة في الـDashboard
**الموقع:** المحتوى ← **مركز الوسائط** (FINAL-ARCHITECTURE-REVIEW §10). Press Kit والحقوق **داخله**، لا وحدة مستقلة.
- **فلاتر:** بانتظار اعتمادك · حقوق تنتهي قريبًا · Press Kit · بلا نص بديل · غير مستخدمة · كبيرة الحجم.
- **درج الأصل:** المعاينة · الاعتماد · قسم "الحقوق والموافقات" (§2) · "مستخدمة في (N)" مع الروابط · استبدال (تبقى الاستخدامات) · أرشفة. **لا حذف نهائي لأصل مستخدم.**
- الإشارات تظهر في "يحتاج انتباه" وتفتح الأصل مباشرة.
- **البيانات:** `media` · `media_usages` · `facts` · `pages` · `page_sections` · `contact_points` · `content_versions` (نسخ بيانات الأصل) · `signals` · `audit_logs`.

**إغلاق البند:** قالب DoD العشري (OPS-054). **أثر النسخ الاحتياطي:** بيانات الحقوق في القاعدة، والأصول الأصلية في نسخة الوسائط (Last Media Backup)، والمشتقة يُعاد توليدها ([`DISASTER-RECOVERY`](DISASTER-RECOVERY.md) §1).

## 8. ما لا يُنفّذ
- لا Stock ولا AI ولا صور Google أو الموقع القديم تلقائيًا، ولا بحث عن بدائل.
- لا رفع لمستندات الموافقة في V1 (مرجع فقط)، ولا كشف وجوه آلي.
- لا DAM أو خدمة وسائط خارجية، ولا علامة مائية.
- لا Press Kit عام قبل اعتماد عناصره، ولا نشر للإرشادات الداخلية.
