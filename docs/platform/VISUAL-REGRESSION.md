## 3. الحتمية: منع الإنذارات الكاذبة (G14-TF-07)
| المصدر | الحل |
|---|---|
| اختلاف الخطوط بين الأجهزة | التشغيل داخل **حاوية Linux ثابتة** بخطوط مضمّنة (نفس صورة الـCI) |
| الوقت ("مفتوح الآن"، العد التنازلي، التواريخ) | **ساعة مجمّدة** (`page.clock`) على وقت ثابت |
| الحركة | `animations: 'disabled'` (موجود في الإعداد) + `prefers-reduced-motion` |
| البيانات | Seeders اصطناعية ثابتة لكل تشغيل |
| التجارب الديناميكية | الحالة "طبيعي" (لا حملة ولا موسم)، مع لقطات منفصلة لكل ثيم عند اختباره، وفحص "العودة للطبيعي" |
| مناطق متغيرة بطبيعتها | **Mask:** شارات الحالة الزمنية، العدادات، الرسوم البيانية ذات `DEMO DATA`، أي محتوى من مصدر خارجي |

## 4. العتبات
- **الإعداد الحالي العام:** `maxDiffPixelRatio: 0.01` (`playwright.config.mjs`).
- **لكل صفحة:** عتبة تبدأ بين 1% و2% من البكسلات + عتبة لون لكل بكسل (`threshold` ≈ 0.2، افتراضي Playwright). تُراجع بعد أول أسبوعين من التشغيل.
- **لا Pixel-perfect** يسبب إنذارات بلا معنى (M32 §26).
- **النتيجة:**
  - تحت العتبة = `PASS`.
  - فوقها = **`FLAG FOR REVIEW`** مع صور (Expected · Actual · Diff) في التقرير.
  - فرق **غير مراجَع** في صفحة حرجة عند الإصدار = **P0** ([`CI-CD-QUALITY-GATES`](CI-CD-QUALITY-GATES.md)).

## 5. اعتماد الـBaseline
1. **أول Baseline** يُنشأ **فقط بعد اعتماد التصميم المرئي** (M-10 + اعتمادك). لا Baseline على الـWireframes منخفضة الدقة.
2. **تحديث الـBaseline** فقط عبر PR مستقل بعنوان واضح "تحديث لقطات مرجعية"، مع صور الفرق مرفقة.
3. **المراجعة:**
   - Claude يراجع كل فرق: مقصود أم انحدار؟
   - **تغيير مقصود في صفحة حرجة** = تغيير تصميم ← يُعرض عليك قبل الاعتماد.
4. **لا قبول تلقائي** للقطات الجديدة أبدًا (`--update-snapshots` لا يُشغَّل في الـCI).
5. الـBaselines تُحفظ في Git بجانب الاختبارات (مجلد `*-snapshots` الافتراضي في Playwright).

## 6. الحالة الآن: معطّل عمدًا
- في `playwright.config.mjs`: `grepInvert: /@visual/` ما لم يُضبط `SHELTER_VISUAL`. أي أن اختبارات `@visual` **لا تعمل افتراضيًا**.
- يوجد اختبار واحد `@visual` على نموذج المنيو (`tests/prototype/responsive.spec.mjs`) **للبنية فقط**.
- التشغيل اليدوي بعد التفعيل: `SHELTER_VISUAL=1 npx playwright test --grep @visual`.
- في `releases.ci_result` تظهر المرحلة: `SKIPPED — NOT ENABLED` حتى التفعيل. **ليست نجاحًا.**
