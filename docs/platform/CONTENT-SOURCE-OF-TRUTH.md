## 1. القواعد
1. **مصدر واحد لكل نوع** (M36 §3). القنوات (الموقع، Schema، GBP، البحث، الـSitemap) **تقرأ وتشتق، ولا تُعدل مباشرة**.
2. تعديل يحدث في قناة خارجية (مثل GBP) = **تغيير خارجي** يُراجع، ولا يكتب فوق المصدر (MASTER-DATA-HUB §10).
   - **الاستثناء الوحيد المسموح:** قيمة خاصة بقناة في `channel_overrides`، **بموافقة الـOwner وسبب**، والأصل يبقى في الـHub (M33 §24).
3. **الإيقاعات أدناه افتراضات تقنية** قابلة للتعديل في **النظام ← الإعدادات**، وتغذي [`CONTENT-HEALTH`](CONTENT-HEALTH.md). ليست قرارات أعمال.
4. **عملية يومية تحتاج كودًا = فجوة معمارية** (OPS-051، M35 §59).
5. الحقل بلا قيمة معتمدة = مخفي + حقيقة معلقة ([`FACT-REGISTRY`](FACT-REGISTRY.md)).

## 4. المشتق والنظامي (لا يحرره أحد يدويًا)
| النوع | المصدر | ملاحظة |
|---|---|---|
| JSON-LD | **مشتق** من الـHub والمحتوى | لا إدخال مستقل (MASTER-DATA-HUB §9) |
| `sitemap.xml` · `robots.txt` · `llms.txt` | **مولّدة** | من المنشور المعتمد فقط |
| فهرس البحث | **مشتق** ([`GLOBAL-SEARCH`](GLOBAL-SEARCH.md)) | يُعاد بناؤه بلا فقد |
| التحليلات | GA4 (خارجي، قراءة عبر Data API) | النمو ← التحليلات |
| الأداء الحقيقي | `rum_metrics` | الجودة ← الأداء |
| سجل البحث المجمّع | `search_query_daily` (**إضافة مقترحة**) | النمو ← البحث |
| الإشعارات والمشاكل | `signals` | الرئيسية + 🔔 |
| التدقيق · الإصدارات · التكاملات · الأعلام | `audit_logs` · `releases` · `integrations` · `feature_flags` | النظام |
| نصوص الواجهة الثابتة | `lang/ar` · `lang/en` (كود) | **المطوّر فقط.** ليست محتوى، ولا يُكتب فيها أي هاتف أو ساعة أو سعر |
| قيم التصميم | `design-system/tokens/tokens.json` | المطوّر بعد ملفات الهوية (M-10) |

## 6. البيانات
كل الجداول أعلاه بأسمائها في PLATFORM-ARCHITECTURE §3. **إضافتان مقترحتان مشتقتان** (تنتظران إدراجهما في PLATFORM-ARCHITECTURE): `search_index` · `search_query_daily` ([`GLOBAL-SEARCH`](GLOBAL-SEARCH.md)).

## 7. مكانه في الـDashboard
عمود "من يعدّل" أعلاه = أقسام FINAL-ARCHITECTURE-REVIEW §10. كل قسم Owner فقط، والتحقق في الخادم (OPS-050).

## 9. ما لا يُفعل
- لا مصدر ثانٍ لأي نوع، ولا Google Sheet للمنيو (CMS-003).
- لا نسخة أسعار أو ساعات داخل الصفحات.
- لا تحرير يدوي للمشتقات.
- لا محتوى أعمال في الكود.
