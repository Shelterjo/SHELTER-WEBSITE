## 3. أمان التصدير حسب التصنيف
| التصنيف | الشرط | الناتج |
|---|---|---|
| PUBLIC / INTERNAL | جلسة Owner | الملف + `export.created` في `audit_logs` |
| CONFIDENTIAL | **تأكيد صريح** في نافذة واضحة (M35 §40) | قناع حيث يلزم + Audit بالنطاق وعدد السجلات |
| SENSITIVE (الهوية) | **مستبعد افتراضيًا.** الكامل = اختيار صريح + Step-up + تحذير | Audit بعلامة "هوية كاملة" (CAREERS-072) |
| الأسرار (`users` · رموز OAuth · المفاتيح) | — | **لا تُصدّر أبدًا** من الخدمة |

**آلية التنفيذ:**
1. الطلب ← مهمة في الـQueue (لا تجميد للواجهة).
2. الملف في منطقة التخزين **`exports`** (خاصة، خارج الجذر العام) باسم بلا PII (الكيان + التاريخ + رقم).
3. صف في **`exports`**: المالك · الكيان · الفلاتر · عدد السجلات · `classification` · `sha256` · `expires_at`.
4. التنزيل عبر رابط موقّع ≤ 60 ثانية مربوط بجلسة الـOwner ← `export.downloaded`.
5. **الحذف الآلي:** بعد أول تنزيل ناجح **أو** بعد 24 ساعة، أيهما أسبق. مهمة مجدولة كل ساعة (`scheduled_job_runs`) ← `export.purged`. فشل الحذف ← إشارة HIGH.
6. **حماية CSV/Excel:** خلية تبدأ بـ`=` `+` `-` `@` تُسبق بـ`'` (Formula injection). UTF-8. PDF بخط عربي صحيح (للتوظيف).
7. منطقة `exports` **مستثناة من النسخ الاحتياطي** حيث يسمح الإعداد (مؤقتة بطبيعتها — يُتحقق في A-08).

## 4. قابلية نقل النظام (M35 §41)
| المكوّن | الشكل القابل للنقل |
|---|---|
| الكود | مستودع Git · Laravel قياسي · لا اعتماد على ميزة خاصة بـCloudways غير مسار `private_html` (قيمة إعداد) |
| قاعدة البيانات | `mysqldump` كامل + المخطط = الـMigrations (المصدر الوحيد) |
| الوسائط العامة | الأصول الأصلية + النسخ المشتقة + `media` (البيانات الوصفية) |
| الملفات الخاصة | `private careers` · `private partnerships` (بنفس مفاتيح `application_attachments`) |
| الإعدادات | `.env.example` بالأسماء. **القيم والمفاتيح منفصلة** لدى الـOwner (نسخة Offline) |
| التكاملات | **تحتاج إعادة ربط** بعد النقل (رموز OAuth مرتبطة بالنطاق والبيئة) |

- **الحزمة الكاملة = مجموعة النسخ نفسها** في [`DISASTER-RECOVERY`](DISASTER-RECOVERY.md) (لا آلية ثانية).
- **الإثبات:** اختبار الاستعادة الدوري على Staging (OPS-042) هو اختبار قابلية النقل نفسه.

## 5. اللوحة في الـDashboard
- **زر "تصدير" موحد** داخل كل قائمة (التوظيف، الشراكات، الاستفسارات، الآراء، المنيو، الفروع، الوسائط) — نفس الخدمة ونفس النافذة.
- **صفحة "تصدير البيانات"** في **النظام ← الإعدادات**: فهرس الكيانات (§2) + آخر الصادرات وحالة كل ملف (جاهز · نُزّل · انتهى). موضعها النهائي يُراجع في Gate H (PO-007).
- **البيانات:** `exports` · منطقة التخزين `exports` · `audit_logs` · `scheduled_job_runs` · `signals` · جداول الكيانات (قراءة فقط).

## 8. ما لا يُنفّذ
- لا تصدير للأسرار، ولا تصدير بلا Audit، ولا روابط تنزيل دائمة.
- لا استيراد ولا API عام في V1.
- لا وجهة نسخ خارجية بتكلفة بلا موافقة (PO-039).
- لا خدمة تصدير ثانية داخل أي وحدة (التوظيف يستخدم نفس الخدمة).
