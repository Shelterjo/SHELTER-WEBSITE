## 1. المبدأ
- **كل مراقب = فحص + عتبة + `dedupe_key`.** النتيجة سطر واحد في `signals` (`kind = ISSUE`) يتحدث ولا يتكرر.
- **الحل التلقائي:** ينجح الفحص مرتين متتاليتين ← `RESOLVED` بواسطة النظام ([`INCIDENTS`](INCIDENTS.md) §5).
- **فحوص خفيفة ومتباعدة** (H-05)، **ولا زحف عدواني** (MON-006).
- **إذا تعطلت قاعدة البيانات نفسها:** تُكتب الإشارة في ملف احتياطي خاص (`storage/app/private/signals-buffer.jsonl`)، وتُنقل إلى `signals` فور عودة القاعدة، بوقت الحدوث الأصلي.

## 3. نموذج الصحة (M35 §44)
- **9 فئات:** CONTENT · SEO · PERFORMANCE · ACCESSIBILITY · SECURITY · PRIVACY · DATA CONSISTENCY · INTEGRATIONS · BACKUPS.
- **حالة الفئة** محسوبة من إشاراتها المفتوحة:
  - أي CRITICAL ← `CRITICAL`.
  - أي HIGH أو MEDIUM ← `NEEDS ATTENTION`.
  - غير ذلك ← `HEALTHY`.
- **BACKUPS = HEALTHY فقط إذا:** آخر نسخة ضمن فاصلها المتوقع **و**آخر اختبار استعادة ناجح ≤ 6 أشهر (M35 §30، DISASTER-RECOVERY §6).
- **بطاقة "الموقع" منفصلة:** ONLINE · DEGRADED (فحص جزئي فشل) · OFFLINE (من المراقب الخارجي). تغذيها إشارات الفئة `OPERATIONS` ([`INCIDENTS`](INCIDENTS.md) §4).
- **لا رقم إجمالي مزيف** (DASH-025).

## 4. مراقب التوفر الخارجي (يحتاج موافقة الـOwner)
**لماذا:** الفحص الداخلي لا يرى توقف الخادم نفسه (I-12).

| الخيار | الغرض | الاستخدام المتوقع | التكلفة / الحصة | البديل المجاني |
|---|---|---|---|---|
| **UptimeRobot** (خطة مجانية) — **الموصى به** | كشف التوقف من خارج الخادم + بريد تنبيه للـOwner | `/health` كل 5 دقائق (≈ 8,640 طلبًا شهريًا) | خطة مجانية. **حدودها وشروط الاستخدام التجاري تُتحقق وقت الطلب.** الحساب باسم المنشأة (PO-037) | GitHub Actions (أدناه) |
| Cloudflare Health Checks | نفس الغرض من Cloudflare | كل 5 دقائق | **حسب خطة Cloudflare (PO-013)** — قد تتطلب خطة مدفوعة | — |
| GitHub Actions (`schedule`) | طلب `/health` دوريًا وفتح Issue عند الفشل | كل 15 دقيقة (التوقيت غير مضمون) | من حصة دقائق CI (I-07، PO-039) | — |

- **لا تفعيل قبل موافقتك.** حتى ذلك: التوقف الكامل يُكتشف بعد العودة فقط (فجوة نبضة المجدول).
- **`/health` العام** يعيد `200 ok` أو `503` فقط: **بلا تفاصيل ولا إصدارات**. التفاصيل في الـDashboard للـOwner.

## 5. فشل الشبكة والخدمات: الهيكل لا ينهار (M35 §21)
| الطبقة | عند الفشل |
|---|---|
| **الهيكل** (Header · التنقل · Footer · الرقم العام) | يُرسم من Cache إعدادات التطبيق (البيانات المعتمدة المنشورة)، فلا يعتمد على استعلام حي |
| **المحتوى الأساسي** (المنيو، الفروع، الصفحات) | HTML من الخادم. إن تعذر: صفحة خطأ SHELTER (M35 §18): أعد المحاولة · الرئيسية · المنيو · التواصل. **بلا Stack trace** |
| **الأجزاء الديناميكية** (التجارب، "مفتوح الآن"، البحث، الخرائط) | كل جزء داخل حد خطأ: الفشل = **لا يُرسم ذلك الجزء فقط**، بلا حاوية فارغة (DX-012، DX-037). "مفتوح الآن" يُخفى بدل عرض حالة قد تكون خاطئة |
| **طلبات المتصفح** | مهلة 8 ثوانٍ. الفشل ← رسالة صغيرة + "أعد المحاولة"، والمدخلات باقية. **المحتوى الأساسي لا يحتاج JavaScript** |
| **القنوات الخارجية** (Google) | فشلها لا يكسر الموقع. الموقع يعرض الـMaster دائمًا (MASTER-DATA-HUB §12) |
| **الـDashboard** | كل وحدة مستقلة: "غير متاح الآن" أو "آخر بيانات محفوظة بتاريخ …"، وبقية الوحدات تعمل (DASH-023) |
| **RUM وأخطاء الواجهة** | `sendBeacon` بلا إعادة محاولة. فشلهما لا يؤثر على الصفحة |

## 6. البيانات
- `signals` · `scheduled_job_runs` · `integrations` · `sync_jobs` · `channel_sync_states` · `rum_metrics` · `releases` · `audit_logs` · `settings` (العتبات والصفحات المهمة).
- **لا جدول مراقبة جديد.**
- سجل الأخطاء الخام: ملف Laravel يومي منظّف من PII، يُحفظ 14 يومًا ثم يُحذف آليًا.

## 7. مكانه في الـDashboard
- **الرئيسية (مركز القيادة):** بطاقات الحالة (الموقع · البيانات · Google · النسخ · الأداء · الـSEO · الأمان) + "يحتاج انتباه".
- **الجودة ← صحة الموقع** (Wireframe `d-health`):
  - المراقبة · الحوادث · الروابط.
  - **المجدول:** آخر تشغيل · التشغيل القادم · الإخفاقات (M35 §49).
  - **النسخ والاستعادة:** آخر نسخة · آخر اختبار استعادة · النتيجة.
- كل سطر يعرض "آخر فحص: قبل …" (DASH-022). 🔔 حسب [`NOTIFICATIONS`](NOTIFICATIONS.md).

## 10. ما ليس منجزًا (NOT DONE)
- **لا كود بعد.** الحالة الصادقة `NOT STARTED`.
- المراقب الخارجي غير معتمد. توكن Cloudflare معلّق (PO-013). مدة سجلات خادم Cloudways غير معروفة (A-10).
- مصدر نبضة النسخ يعتمد على Cloudways audit (A-08)، بلا Cloudways API key (G14-CF-17).
- العتبات **افتراضات تقنية** تُضبط بعد التحقق T+7d بعد الإطلاق.
