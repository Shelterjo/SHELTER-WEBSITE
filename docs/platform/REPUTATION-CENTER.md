# REPUTATION CENTER — سمعة الفروع على Google ومسار الرد

| البند | القيمة |
|---|---|
| **الغرض** | لكل فرع: التقييم، وعدد المراجعات، والجديد منها، والاتجاه، وما يحتاج ردًا — من **Google Business Profile الرسمي فقط** — ومسار رد لا يُنشر إلا باعتماد الـOwner |
| **الحالة** | `SPEC — READY FOR BUILD` · التنفيذ: `NOT STARTED` · التكامل: **`PENDING INTEGRATION`** |
| **مرحلة البناء (M36 §6)** | **PHASE 5** (Google Business Profile). تُبنى الوحدة بحالة `PENDING INTEGRATION` قبل الوصول |
| **الأولوية** | P1 |
| **المتطلبات** | OPS-028 · OPS-029 · OPS-048 · OPS-052 · OPS-053 · GBP-007 · GBP-009 · GBP-015 · PRIV-010 · INT-006 · PERM-007 · AUDIT-001 · D-043 · M32 §13 §14 |
| **التعارضات المحسومة** | G14-CF-04 (GBP API الرسمية ≠ Places المدفوعة) · G14-CF-05 (كل رد = كتابة على GBP) |
| **قرارات مفتوحة** | **PO-009:** (1) طلب وصول Business Profile API من Google · (2) OAuth بحساب Owner/Manager للفرعين · (3) نشر الرد المعتمد من الـDashboard مباشرة أم نسخه يدويًا · **PO-019:** مدة الاحتفاظ بنسخ المراجعات |

## 1. النطاق
| V1 | لاحقًا |
|---|---|
| الوحدة بحالة `PENDING INTEGRATION` · بعد الوصول: قراءة يومية للمراجعات · المؤشرات الست لكل فرع · مسار الرد بالاعتماد · "نسخ الرد" إن لم تُمنح صلاحية الكتابة | اقتراح رد بالـAI وقت التشغيل (مدفوع — بموافقة) · تحليل المشاعر الموسوم · منشورات GBP (قرار منفصل) |

## 2. القراءة (بعد PO-009 فقط)
- **المصدر:** Google Business Profile APIs الرسمية (نقاط المراجعات لكل موقع). **مجانية بطلب وصول**، وليست Places API المدفوعة (D-043).
- **الربط:** `BR-DRIVE` / `BR-HOUSE` ← `locations/{id}` عبر `external_references`.
- **المزامنة:** مهمة يومية في `sync_jobs` (قناة `gbp_reviews`) مع إعادة المحاولة المعتمدة (1 ← 5 ← 30 دقيقة ← 6 ساعات، 5 محاولات). **لا استدعاء للـAPI عند فتح الصفحة** (من النسخة المخزنة).
- **التخزين:** صف لكل مراجعة في `reviews`: الفرع · معرّف المراجعة · النجوم · النص · اسم العرض للمراجع · وقت الإنشاء والتحديث · الرد الحالي على Google. إجماليات Google (`averageRating` · `totalReviewCount`) في `channel_sync_states` لكل فرع.
- **المرآة:** مراجعة حُذفت على Google تُحذف محليًا في المزامنة التالية.
- **فشل الـAPI لا يكسر الـDashboard:** يُعرض "آخر مزامنة ناجحة" + إشارة.

| المؤشر (M32 §13) | الحساب |
|---|---|
| Rating · Reviews Count | من إجماليات Google |
| Recent Reviews | آخر 10 مراجعات |
| New Reviews | منذ آخر زيارة للـOwner لهذه الوحدة |
| Review Trends | متوسط النجوم والعدد شهريًا من `reviews` (موسوم: "من المراجعات المتاحة عبر API") |
| Needs Reply | بلا رد على Google وغير مستبعدة يدويًا |

## 3. مسار الرد — لا نشر تلقائي أبدًا
```
المراجعة ← مسودة (يكتبها الـOwner، أو اقتراح موسوم AI ASSISTED) ← تعديل الـOwner ← اعتماد الـOwner ← نشر على GBP
                                                                                            └─ بلا صلاحية كتابة: "نسخ الرد" + رابط المراجعة
```
| الحالة | من ينقلها | القاعدة |
|---|---|---|
| `DRAFT` | الـOwner أو اقتراح AI | الاقتراح موسوم **AI ASSISTED** ولا يحتوي حقائق مخترعة (عروض، تعويضات، وعود). أي حقيقة من سجل الحقائق فقط |
| `APPROVED` | **الـOwner فقط** (جلسته) | كل رد اعتماد مستقل (GBP-009). لا اعتماد جماعي |
| `PUBLISHED` | النظام بعد الاعتماد | Endpoint النشر **يرفض** أي حالة غير `APPROVED`. نتيجة Google تُعرض بوضوح، والفشل = إشارة |
| `COPIED` | الـOwner | عند غياب صلاحية الكتابة (G14-CF-05) |
| `DISMISSED` | الـOwner | لا يحتاج ردًا |

- **حتى 5 نجوم:** لا رد آلي.
- **تعديل أو حذف رد منشور** = كتابة على GBP ← نفس المسار.
- كل انتقال ← `audit_logs` (مع علامة "اقتراح AI اعتمده الـOwner" عند الحاجة — OPS-053). نسخ المسودة في `content_versions`.
- **اقتراح AI في V1:** معطّل حتى موافقة على خدمة مدفوعة (§7). البديل المجاني: الـOwner يكتب، أو Claude يقترح داخل جلسة العمل يدويًا.

## 4. قواعد ثابتة
- **لا Scraping** لـGoogle Maps أو أي مصدر (INT-006). بلا وصول = `PENDING INTEGRATION` وبلا أرقام.
- **لا Review gating:** لا توجيه للراضين فقط لترك تقييم، ولا إخفاء الطريق عن غيرهم ([`VOICE-OF-CUSTOMER`](VOICE-OF-CUSTOMER.md) §2).
- **المراجعات لا تُعرض على الموقع ولا تدخل الـSchema** (PRIV-010، لا Review markup ذاتي).
- **المشاعر (اختياري):** أي تحليل = **"AI ASSISTED ANALYSIS"**، ليس حقيقة ولا رقمًا مطلقًا. الافتراضي: النجوم والاتجاه فقط.
- أسماء المراجعين ونصوصهم بيانات شخصية = **CONFIDENTIAL** ([`DATA-CLASSIFICATION`](DATA-CLASSIFICATION.md)). الاحتفاظ `PENDING LEGAL REVIEW (PO-019)`.
- الإبلاغ عن مراجعة مسيئة إجراء يدوي من الـOwner داخل GBP، لا من النظام.

## 5. اللوحة في الـDashboard
**الموقع:** الأعمال ← **السمعة** (FINAL-ARCHITECTURE-REVIEW §10).
- بطاقة لكل فرع: المؤشرات الست + حالة الربط. قبل الوصول: `PENDING INTEGRATION` + شرح السبب، **بلا أرقام**.
- قائمة المراجعات مع فلتر "تحتاج ردًا"، ودرج الرد (المراجعة · المسودة · تعديلك · اعتمادك · النشر).
- **الإشارات (حسب [`NOTIFICATIONS`](NOTIFICATIONS.md)):** مراجعة تحتاج ردًا = `EVENT` بأولوية ACTION_REQUIRED (`review:{id}`)، تُحل بالرد أو "لا يحتاج ردًا" · فشل المزامنة أو انتهاء الرمز = `ISSUE` HIGH بفئة `INTEGRATIONS` ("أعد ربط حساب Google") · عدد "تحتاج ردًا" في مركز القيادة.
- **البيانات:** `reviews` (**إضافة مقترحة** لـPLATFORM-ARCHITECTURE §3) · `branches` · `external_references` · `integrations` (الحالة والنطاق والانتهاء) · `settings` (رمز OAuth مشفّر، SENSITIVE) · `sync_jobs` · `channel_sync_states` · `content_versions` · `audit_logs` · `signals`.

## 6. اختبارات القبول
| # | الاختبار | المتوقع |
|---|---|---|
| RP-T01 | الوحدة بلا ربط | `PENDING INTEGRATION`، ولا رقم ولا مراجعة حقيقية |
| RP-T02 | مزامنة من بيانات API وهمية (Fixture) لفرعين | المؤشرات الست صحيحة لكل فرع |
| RP-T03 | استدعاء Endpoint النشر لمسودة `DRAFT` | رفض، ولا طلب كتابة إلى Google |
| RP-T04 | اعتماد ثم نشر بصلاحية كتابة وهمية | طلب كتابة واحد، والحالة `PUBLISHED`، وسطر Audit لكل خطوة |
| RP-T05 | بلا صلاحية كتابة | المسار ينتهي بـ"نسخ الرد" ورابط المراجعة |
| RP-T06 | مراجعة 5 نجوم جديدة | لا رد آلي ولا مسودة منشورة |
| RP-T07 | فشل API (500 / رمز منتهي) | الـDashboard يعمل من النسخة المخزنة + إشارة HIGH |
| RP-T08 | مراجعة محذوفة في الـFixture | تُحذف محليًا |
| RP-T09 | فحص الكود | لا طلبات إلى `maps.google.com` أو Places API |
| RP-T10 | الصفحات العامة والـSchema | لا نص مراجعة ولا `Review`/`AggregateRating` ذاتي |
| RP-T11 | الوحدة | 20 عرضًا RTL/LTR + axe + `401/403` بلا جلسة Owner |

**إغلاق البند:** قالب DoD العشري (OPS-054)، ومنه سيناريوهات فشل الخدمة الخارجية. **أثر النسخ الاحتياطي:** `reviews` قابلة لإعادة البناء من GBP؛ المسودات والاعتمادات و`audit_logs` ضمن نسخة القاعدة.

## 7. الخدمات المدفوعة (خيارات فقط)
| الخدمة | الغرض | الاستخدام المتوقع | التكلفة / الحصة | البديل المجاني |
|---|---|---|---|---|
| LLM API وقت التشغيل (مثل Claude API) | اقتراح رد مسودة | مسودة لكل مراجعة جديدة (فرعان) | مدفوع لكل Token + **يمرر نص المراجعة لطرف ثالث** (غير مقترح في V1) | الـOwner يكتب، أو Claude داخل جلسة العمل |
| Google Places API | تقييمات | — | مدفوع لكل طلب (**مرفوض**، D-043) | Business Profile API الرسمية |
| منصات سمعة SaaS | تجميع وردود | — | اشتراك (**غير مقترح**) | هذه الوحدة |

## 8. ما لا يُنفّذ
- لا نشر رد بلا اعتماد، ولا ردود آلية، ولا اعتماد جماعي للردود.
- لا Scraping، ولا Places API، ولا أرقام قبل الربط الرسمي.
- لا عرض للمراجعات على الموقع أو في الـSchema، ولا Review gating.
- لا Sentiment كحقيقة، ولا AI مدفوع بلا موافقة.
