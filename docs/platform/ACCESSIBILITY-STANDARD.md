| البند | القيمة |
|---|---|
| **الغرض** | معيار واحد ملزم لكل صفحة ومكوّن ونموذج في الموقع والـOwner Dashboard، وطريقة قياسه وعرض صحته للـOwner |
| **الحالة** | `SPEC — READY FOR BUILD` · التنفيذ: `NOT STARTED` |
| **مرحلة البناء (M36 §6)** | يسري من **PHASE 1** (مكونات Design System) على كل المراحل · لوحة "الوصولية" في **PHASE 6** · بوابة الـCI في **PHASE 7** |

| **المتطلبات** | A11Y-001 … A11Y-020 · MEDIA-012 · MEDIA-016 · DX-027 · OPS-048 · OPS-054 · M32 §31 §32 · M36 §12 §13 · D-061 |
| **المراجع** | [`DESIGN-SYSTEM-STANDARD`](../DESIGN-SYSTEM-STANDARD.md) §3 §5 §7 · [`menu-ia/ACCESSIBILITY-CHECKLIST`](../menu-ia/ACCESSIBILITY-CHECKLIST.md) · [`qa/RESPONSIVE-QA-MATRIX`](../qa/RESPONSIVE-QA-MATRIX.md) · `tooling/viewports.mjs` |

## 1. الهدف والنطاق
- **الهدف: WCAG 2.2 AA** للموقع العام (AR/EN) والـDashboard والنماذج (التوظيف، الشراكات، الاستفسارات، الآراء).
- **axe بلا أخطاء جدية شرط لازم وليس دليل امتثال.** الفحص اليدوي جزء من الحالة (A11Y-003).
- **V1:** القواعد §2–§3 + الفحص الآلي في كل تشغيل + القائمة اليدوية لكل قالب متغيّر + لوحة "الوصولية". **لاحقًا:** تدقيق خارجي اختياري، وصفحة "بيان الوصولية" بقرار الـOwner.

## 2. خصوصيات العربية وRTL
| القاعدة | التنفيذ |
|---|---|
| اللغة والاتجاه | `<html lang="ar" dir="rtl">` / `lang="en" dir="ltr">`. النص الإنجليزي داخل العربية بـ`lang="en"` والعكس (A11Y-013) |
| النص المختلط | الأسماء المختلطة والأسعار داخل `<bdi>`. لا انقلاب للرموز والأرقام |
| CSS منطقي | `margin-inline` · `padding-inline` · `inset-inline`. **لا left/right ثابتة** في المكونات |
| الأيقونات | الاتجاهية تنعكس (الأسهم)، وغير الاتجاهية لا تنعكس (البحث، الإغلاق) |
| ترتيب التركيز | يتبع ترتيب القراءة في الاتجاهين |
| النطق | السعر مقروء كاملًا ("3.50 دينار أردني"). الأسماء بالأحرف الكبيرة تُقرأ ككلمات (A11Y-014، A11Y-015) |
| الأخطاء | رسائل عربية واضحة بلا مصطلحات تقنية، مرتبطة بالحقل |

## 3. القواعد (لكل مكوّن في `x-ui.*`)
| المجال | القاعدة | معيار WCAG |
|---|---|---|
| لوحة المفاتيح | كل عنصر تفاعلي بـTab وبترتيب منطقي. رابط "تخطَّ إلى المحتوى" أولًا. لا مصيدة تركيز. النوافذ بـ`<dialog>` (ADR-001): حبس التركيز، و`Esc`، وعودة التركيز للمصدر | 2.1.1 · 2.1.2 · 2.4.3 |
| التركيز المرئي | حلقة 3px من Token `focus`، **لا تُزال**، بتباين ≥ 3:1. **لا تختفي تحت الأشرطة اللاصقة** (`scroll-padding`) | 2.4.7 · **2.4.11** |
| التكبير 200% وإعادة التدفق | لا تمرير أفقي ولا قص عند 320px CSS وعند عرض `zoom200-1280`. لا منع لـPinch zoom (A11Y-018) | 1.4.4 · 1.4.10 |
| تقليل الحركة | `prefers-reduced-motion` ← صفر حركة وبديل ثابت، **بما فيها الثيمات الموسمية** (DX-027). لا وميض. لا صوت تلقائي (MEDIA-016) | 2.3.1 · 2.2.2 · 1.4.2 |
| أهداف اللمس | **≥ 44×44px** على أجهزة اللمس، ومسافة ≥ 8px (A11Y-017). الحجم Small (36) **فقط** للجداول الكثيفة مع `pointer: fine` | **2.5.8** |
| السحب | أي سحب (Bottom sheet، تقويم الـDashboard) له بديل بنقرة | **2.5.7** |
| التباين | النص ≥ 4.5:1، والكبير ≥ 3:1، والإطارات والأيقونات ≥ 3:1 — **لكل ثيم** بما فيها الموسمية | 1.4.3 · 1.4.11 |
| اللون وحده | الحالات (مفتوح/مغلق، نجح/فشل) بنص أو أيقونة أيضًا (A11Y-016) | 1.4.1 |
| النماذج | Label ظاهر (لا Placeholder وحده) · الخطأ نصًا ومرتبطًا بـ`aria-describedby` · ملخص أخطاء · **لا مهلة زمنية** على المستخدم · لا إعادة إدخال لما أُدخل | 3.3.1 · 3.3.2 · **3.3.7** |
| مصادقة الـOwner | Passkey متاح · **اللصق مسموح** في حقول كلمة المرور وTOTP · لا اختبار إدراكي | **3.3.8** |
| انتهاء الجلسة | تنبيه قبل انتهاء الخمول بدقيقتين مع زر "متابعة". انتهاء جلسة نموذج عام **لا يمسح المدخلات** | 2.2.1 |
| الصور | نص بديل AR/EN من مركز الوسائط (MEDIA-012). الزخرفية `alt=""` | 1.1.1 |
| البنية | عنوان H1 واحد، وتسلسل صحيح، وLandmarks. ARIA فقط حيث يلزم (A11Y-009، A11Y-012) | 1.3.1 · 4.1.2 |
| المساعدة الثابتة | رابط التواصل في نفس الموضع في كل الصفحات | **3.2.6** |
| الإعلانات الحية | نتائج البحث وحالات الحفظ بـ`aria-live="polite"` بعد توقف الكتابة (A11Y-010) | 4.1.3 |

> **أرقام WCAG 2.2 الجديدة بالخط العريض.** أي استثناء = قرار موثق بسببه، وليس صمتًا.

## 4. الاختبار
| النوع | الأداة / الطريقة | البوابة |
|---|---|---|
| آلي | `@axe-core/playwright` بالوسوم `wcag2a · wcag2aa · wcag21a · wcag21aa · wcag22aa` على **كل قالب × AR/EN × مصفوفة `tooling/viewports.mjs`**، **ويشمل حالات النوافذ والنماذج والأخطاء** (سد فجوة A11Y-004) | **0 Serious/Critical وإلا فشل** |
| آلي مساند | Lighthouse Accessibility | مؤشر فقط، ليس بوابة |
| يدوي | لوحة مفاتيح فقط · VoiceOver (iOS) · TalkBack (Android) · NVDA (Windows) · تكبير 200% · تقليل الحركة · RTL/LTR | لكل قالب جديد أو متغيّر قبل الإصدار |
| قائمة يدوية | [`menu-ia/ACCESSIBILITY-CHECKLIST`](../menu-ia/ACCESSIBILITY-CHECKLIST.md) تبقى للمنيو، وبنودها العامة (الاتجاه، الكيبورد، التركيز، قارئ الشاشة، النوافذ، التباين) **تُطبق على كل قالب** | النتيجة تُسجل (§5) |
| أثناء النشر | Publish Guard: النص البديل AR/EN ناقص · عناوين مقفزة · تباين ثيم غير معتمد (فحوص خفيفة بلا متصفح — G14-TF-04) | WARNING/BLOCKING حسب القاعدة |

**الاختبارات القائمة (تُعاد استخدامها لا تُكرر):** `tooling/tests/prototype/menu-wireframe.spec.mjs` · `careers.spec.mjs` · `dashboard.spec.mjs` (axe Serious/Critical) · `responsive.spec.mjs` · `tooling/tests/app/menu.spec.mjs`. الأمر: `npm run test:a11y`. Chromium محليًا، وFirefox/WebKit في الـCI (`SHELTER_ALL_BROWSERS=1`).

## 5. صحة الوصولية في الـDashboard
**الموقع:** الجودة ← **الوصولية** (FINAL-ARCHITECTURE-REVIEW §10). فئة `ACCESSIBILITY` في نموذج الصحة.

| العمود (M32 §32) | المصدر |
|---|---|
| المشكلة (بلغة الـOwner) · الصفحة · الشدة · **المصدر: آلي / يدوي** · الإصلاح المقترح · زر يفتح المكان | `signals` بفئة `ACCESSIBILITY` |

- **الأنواع (A11Y-020):** تباين · اسم مفقود · لوحة مفاتيح · ARIA · عنوان · نص بديل · لغة · تركيز النوافذ.
- **مصادر الإشارات:** (1) نتائج axe من الـCI على Staging تُرفق بـ`releases` وتُحوّل إلى إشارات · (2) فحوص Publish Guard · (3) نتائج الفحص اليدوي (يسجلها Claude أو الـOwner) مع تاريخ آخر فحص لكل بند.
- **لا axe على سيرفر الإنتاج** (لا متصفح Headless على Cloudways — G14-TF-04).
- حل المشكلة في الفحص التالي يغلق الإشارة آليًا.
- **البيانات:** `signals` · `releases` · `media` (النص البديل) · `page_sections` · `audit_logs`.

## 6. اختبارات القبول
| # | الاختبار | المتوقع |
|---|---|---|
| AX-T01 | axe لكل قالب × AR/EN × 20 عرضًا، والنوافذ والنماذج مفتوحة وبحالة خطأ | 0 Serious/Critical |
| AX-T02 | Tab من أول الصفحة لآخرها في كل قالب AR/EN | ترتيب منطقي، والتركيز ظاهر وغير محجوب |
| AX-T03 | فتح وإغلاق كل نافذة بلوحة المفاتيح | حبس التركيز، و`Esc` يغلق، والتركيز يعود للمصدر |
| AX-T04 | عرض `zoom200-1280` و`m320` | لا تمرير أفقي ولا قص (`scrollWidth ≤ clientWidth`) |
| AX-T05 | `prefers-reduced-motion: reduce` مع ثيم موسمي نشط | لا `animation`/`transition` فعّالة (فحص الأنماط المحسوبة) |
| AX-T06 | قياس كل عنصر تفاعلي على عروض اللمس | ≥ 44×44px |
| AX-T07 | `html[lang][dir]` وحقول `lang` الثانوية | صحيحة في AR وEN |
| AX-T08 | حقل كلمة مرور الـOwner وTOTP | اللصق يعمل |
| AX-T09 | أي سحب في الـDashboard | يوجد بديل بنقرة يُنجز نفس الإجراء |
| AX-T10 | خطأ axe مزروع على Staging | إشارة في لوحة "الوصولية" بالمصدر "آلي"، والنقر يفتح الصفحة |
| AX-T11 | القائمة اليدوية لأي قالب متغيّر | مسجلة بتاريخها قبل اعتماد الإصدار |

**إغلاق البند:** قالب DoD العشري (OPS-054). **أثر النسخ الاحتياطي:** لا بيانات جديدة غير `signals` ونتائج `releases` ضمن نسخة القاعدة.

## 7. ما لا يُنفّذ
- **لا "Accessibility overlay"** أو أداة طرف ثالث تدّعي الإصلاح الآلي.
- لا ادعاء علني بالامتثال الكامل بلا تدقيق، ولا بيان وصولية بلا قرار الـOwner.
- لا هدف AAA في V1 (باستثناء قاعدة اللمس 44px المعتمدة).
- لا axe على Production، ولا أداة اختبار مكررة لما في `tooling/`.
