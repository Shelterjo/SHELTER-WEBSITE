# SAFE MODE — وضع الأمان ومفاتيح الطوارئ والصيانة

| البند | القيمة |
|---|---|
| **الغرض** | إذا سبّبت حملة أو ثيم موسمي أو إضافة اختيارية مشكلة: يوقفها الـOwner **بضغطة واحدة**، ويبقى الموقع الأساسي يعمل. والصيانة الكاملة **آخر حل** |
| **الحالة** | `SPEC — READY FOR BUILD` · التنفيذ: `NOT STARTED` |
| **مرحلة البناء (M36 §6)** | **PHASE 1:** جدول `feature_flags` وقراءته من الخادم · **PHASE 3:** "أوقف الآن" في التجارب · **PHASE 6:** Safe Mode ومفاتيح الطوارئ كاملة |
| **الأولوية** | P0 |
| **المتطلبات** | M32 §23 · §24 · M31 §4 · §11 · §29 · M35 §19 · §58 · OPS-023 · OPS-024 · DX-013 · DX-020 · DX-021 · DX-037 · CAMP-007 · G14-CF-07 · G14-CF-19 · G14-TF-08 · G14-TF-10 · AC-5 (FINAL-ARCHITECTURE-REVIEW §6) |
| **المراجع الملزمة** | [`PLATFORM-ARCHITECTURE`](../architecture/PLATFORM-ARCHITECTURE.md) §3.1 (`feature_flags`) · [`DYNAMIC-EXPERIENCE-ENGINE`](../DYNAMIC-EXPERIENCE-ENGINE.md) §2–§5 · [`SECURITY-CENTER`](SECURITY-CENTER.md) §2 · [`CACHE-CDN`](CACHE-CDN.md) |

## 1. القاعدة: نظام أعلام واحد
- **Safe Mode، والإيقاف الطارئ، والصيانة = أعلام في `feature_flags`.** لا نظام ثانٍ (FINAL-ARCHITECTURE-REVIEW §5، G14-CF-07).
- **الإيقاف الطارئ لكل تجربة يبقى حيث صُمم:** عمود `experiences.emergency_disabled` في محرك التجارب (DX-013، DX-020). **لا نسخة مكررة منه في `feature_flags`.**
- **الترتيب دائمًا:** إيقاف عنصر واحد ← Safe Mode ← الصيانة الكاملة (AC-5).

| العلم / المفتاح | النطاق | الافتراضي | الأثر |
|---|---|---|---|
| `safe_mode` | الموقع كله | `false` | يوقف الطبقة الديناميكية كاملة (§2) |
| `experiences.emergency_disabled` (عمود) | تجربة واحدة | `false` | "أوقف الآن" لحملة أو إعلان أو تكريم واحد |
| `motion.seasonal` | الموقع كله | `true` | إيقاف حركة الثيمات الموسمية فقط (تبقى اللمسات الثابتة `reduced_motion_static`) |
| `integration.{key}.enabled` | تكامل اختياري واحد | حسب التكامل | إيقاف تحميله **من جهة الموقع فقط** (خريطة مضمّنة، Widget). **لا يعدّل أي إعداد في Google** (G14-CF-19) |
| `maintenance_mode` | الموقع العام كله | `false` | الصيانة الكاملة (§4) |

**مفاتيح الطوارئ الأربعة (OPS-024):**
1. إيقاف الحملة النشطة ← "أوقف الآن" على التجربة.
2. إيقاف الحركة الموسمية ← `motion.seasonal`.
3. إخفاء إعلان ← "أوقف الآن" على الإعلان.
4. إيقاف تكامل اختياري مُسبب للمشكلة ← `integration.{key}.enabled`.

## 2. ما يبقى وما يتوقف
| الجزء | عادي | Safe Mode | الصيانة الكاملة |
|---|---|---|---|
| المنيو · الأسعار · التوفر | ✅ | ✅ | ❌ |
| الفروع · الساعات · "مفتوح الآن" | ✅ | ✅ | ❌ |
| التواصل · التنقل · الصفحات الأساسية | ✅ | ✅ | ❌ |
| النماذج (INQ · JOB · FR) | ✅ | ✅ | ❌ تُغلق برسالة، والمدخلات لا تضيع |
| الحملات · الإعلانات · النوافذ المنبثقة · العدّ التنازلي | ✅ | ❌ | ❌ |
| الثيمات الموسمية والحركة | ✅ | ❌ | ❌ |
| **إشعار طارئ حرج** (مثل "الفرع مغلق اليوم" — CAMP-007) | ✅ | ✅ **نصًا ثابتًا بلا حركة**، ما لم يُخفِه الـOwner صراحة (G14-TF-08) | يظهر داخل صفحة الصيانة إن كان نشطًا |
| تكاملات اختيارية (خرائط مضمّنة، Widgets) | ✅ | ❌ | ❌ |
| سكربتات غير أساسية (حزم الثيمات، مكتبة الحركة) | حسب الحاجة | ❌ لا تُحمّل | ❌ |
| RUM والتحليلات (حسب الموافقة) | ✅ | ✅ (مراقبة، ليست طبقة عرض) | ❌ |
| الـDashboard | ✅ | ✅ | ✅ |
| استجابة HTTP العامة | `200` | `200` | **`503` + `Retry-After`** (يفهمه Google كتوقف مؤقت) |

- **صفحة الصيانة:** بهوية SHELTER، والرقم العام المعتمد `0799009436` (D-057).
  - نص الرسالة: `MISSING — OWNER INPUT REQUIRED` (لا نص مخترع).
- **إطفاء Safe Mode** يعيد الحالات السابقة **بلا فقدان بيانات:**
  - المجدول يعود حسب جدوله.
  - المنتهي يبقى منتهيًا.
  - المُوقف يدويًا يبقى موقفًا.

## 3. من يشغّل، وكيف
| | Safe Mode · مفاتيح الطوارئ | الصيانة الكاملة |
|---|---|---|
| **من** | الـOwner فقط. فحص من الخادم (Policy)، لا إخفاء أزرار (M35 §58) | الـOwner فقط، **وبموافقته الصريحة** حتى لو حضّرها Claude |
| **متى** | أي مشكلة في الطبقة الديناميكية | **فقط** لترحيل أو حادثة أمنية (AC-5) |
| **التأكيد** | **تأكيد واحد** (Wireframe `d-safe-mode`)، مع جلسة حديثة أقل من 10 دقائق، وإلا Step-up بـPasskey أو TOTP (SECURITY-CENTER §2، G14-TF-10) | كتابة كلمة "صيانة" + Step-up دائمًا + سبب إلزامي + وقت انتهاء متوقع |
| **السبب** | اختياري، ويُسجّل | إلزامي |
| **الموبايل** | متاح كاملًا (DASH-028) | متاح |

**التنفيذ الفوري (G14-TF-08):**
- العلم يُقرأ من الخادم في كل طلب (Cache تطبيق ≤ 10 ثوانٍ، يُبطل فورًا عند التغيير).
- إبطال وسوم HTML في Cloudflare إن توفر توكن الإبطال المحدود (PO-013).
- وإلا يكفي زمن تخزين HTML القصير ([`CACHE-CDN`](CACHE-CDN.md)).
- **الهدف:** الأثر ظاهر للزوار خلال 60 ثانية، بلا نشر كود.

## 4. التدقيق والتنبيه
- **كل تبديل = سطر `audit_logs`:** من · متى · السبب · قبل/بعد.
  - `safe_mode.enabled` / `disabled` · `maintenance.enabled` / `disabled` · `integration.disabled` · `experience.emergency_disabled` · `motion.seasonal.disabled`.
- **Safe Mode مفعّل** ← شريط ثابت في الـDashboard "وضع الأمان مفعّل منذ …" + إشارة `EVENT` بأولوية IMPORTANT.
  - بعد 24 ساعة ← `ISSUE` MEDIUM "وضع الأمان ما زال مفعّلًا".
- **الصيانة مفعّلة** ← `ISSUE` CRITICAL ثابت حتى الإطفاء ("الموقع العام مغلق للزوار الآن").
- **فشل محرك التجارب** يعزل نفسه دون Safe Mode (DX-037). Safe Mode قرار الـOwner، وليس آلية الحماية الوحيدة.

## 5. البيانات
- `feature_flags`: `key` · `value` · `scope` · `reason` · `updated_by` · `updated_at`.
- `experiences.emergency_disabled` · `audit_logs` · `signals` · `settings` (نص صفحة الصيانة بعد اعتماده).
- **لا جدول جديد.**

## 6. مكانه في الـDashboard
- **زر ⚠️ "وضع الأمان"** في الشريط العلوي، ظاهر دائمًا (GAP-CLOSURE-PLAN §C).
  - نافذته تعرض: ما سيتوقف · ما يبقى · رابط "لإيقاف عنصر واحد: النشط الآن ← أوقف الآن".
- **التجارب ← النشط الآن:** "أوقف الآن" لكل تجربة (DX-020) + تحذيرات التعارض.
- **النظام ← الإعدادات ← الأعلام:** الحركة الموسمية · مفاتيح التكاملات الاختيارية · الصيانة الكاملة (بقيودها).

## 9. ما ليس منجزًا (NOT DONE)
- **لا كود بعد.** الحالة الصادقة `NOT STARTED`.
- **نص صفحة الصيانة:** `MISSING — OWNER INPUT REQUIRED`.
- إبطال Cloudflare الفوري معلّق على توكن محدود (PO-013).
- قائمة التكاملات الاختيارية تُبنى مع كل تكامل يُعتمد (لا شيء منها معتمد الآن).
