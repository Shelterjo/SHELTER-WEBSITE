## قواعد كل خطوة
1. **لا كلمة مرور ولا مفتاح في المحادثة أبدًا.** نستخدم الدعوات والأدوار. أي سر يذهب إلى GitHub secrets أو `.env` على السيرفر، وتضعه أنت بنفسك.
2. **أقل صلاحية:** قراءة أولًا. صلاحية الكتابة تُطلب في وقتها، وتُسحب بعد الانتهاء.
3. **كل تغيير على Production** (DNS، التحويلات، Google Business، نشر GTM) = ملخص ← موافقتك ← تنفيذ.
4. **السكوت ليس موافقة.** الخطوة التالية لا تبدأ إلا برسالة صريحة منك.
5. **كل صلاحية تُسجّل** في سجل التكاملات: ماذا، ولماذا، ومتى تنتهي.
