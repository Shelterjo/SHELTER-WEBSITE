# 04 — Owner Dashboard: Franchise & Partnerships Module IA (Deliverable 15)

> **الحالة:** `DRAFT — PENDING OWNER REVIEW` (M29 §37–§45، §78–§80) · **Module أصلي داخل الـDashboard، وليس iframe.**
> **الاسم في القائمة:** "الشراكات" / "Partnerships" (مختصر). العنوان الكامل داخل الصفحة: Franchise & Partnerships.

## 3. القائمة والعرض
- **الأعمدة الافتراضية:** المتقدم · الدولة · المدينة · السوق المقترح · تاريخ الطلب · المرحلة · آخر تحديث.
  - أي حقل تأهيلي يُضاف بعد اعتماده.
- **البحث:** المتقدم · الهاتف · البريد · الدولة · المدينة · السوق · رقم الطلب.
- **الفلاتر:** المرحلة · الدولة · المدينة · التاريخ · السوق.
- **أنماط تحكم مشتركة مع وحدة التوظيف** (Applications Core): الفلاتر المحفوظة، والأعمدة، والكثافة، وحجم الصفحة، والترقيم التقليدي.
- **عرض سريع** (Side panel) + **صفحة كاملة** تتضمن:
  - بيانات الطلب، والمرحلة.
  - الملاحظات المتعددة، والاجتماعات.
  - المرفقات (إن فُعّلت)، ومعلومات السوق.
  - تاريخ المراحل، والـAudit.
  - الطلبات السابقة المكتشفة.
- **الاجتماعات:** التاريخ · الوقت · المكان أو القناة (قائمة قابلة للإعداد) · ملاحظات داخلية · الحالة. **لا تُعرض للمتقدم.**

## 4. قواعد ثابتة
1. **لا قبول ولا رفض آلي، ولا تأهيل أو تقييم استثماري آلي.**
   - AI مستقبلًا للتلخيص والتنظيم وإبراز النواقص والتكرار فقط.
   - **القرار بشري.**
2. **التكرار:** إشارة "طلبات سابقة" بالهاتف والبريد واسم الشركة، **بلا دمج**.
3. **الصلاحيات:** **V1 = الـOwner فقط.** القرار مجمّد: لوحة التحكم للـOwner وحده، ولا يُنشأ أي مستخدم Franchise أو غيره في V1.
   - **التحقق Server-side** في كل طلب، كما في `../RECRUITMENT-PERMISSIONS.md` §1.
   - **المعمارية جاهزة للمستقبل:** إذا أنشأ الـOwner لاحقًا مستخدمًا **صراحةً**، يمنحه صلاحيات مختارة (مثل `franchise.view` / `franchise.manage` / `franchise.export`).
   - **لا وصول تلقائي لأحد**، والـOwner السلطة الأعلى.
4. **سجل التدقيق:** إنشاء طلب · تغيير مرحلة · ملاحظة · اجتماع · مستند · أرشفة · تصدير · أي إجراء حساس.
   - **الحقول:** Actor · Action · Target · Timestamp · Before · After.
5. **ممنوع في الحزمة العامة للموقع:** النماذج المالية، والأدلة، والعقود، والـSOPs، وتحليلات الأسواق، وجداول الرسوم، وملفات الربحية (§77).
