## UX النموذج (M29 §33)
- **صفحة واحدة منظمة** مقابل **خطوات قصيرة**: (عنك ← السوق ← الخبرة ← الفرصة ← مراجعة وإرسال).
  - **يُختبر في الـWireframes** بنفس منهج نموذج التوظيف: عدد الشاشات، والتفاعلات، وظهور أول خطأ.
  - **يُختار الأقل احتكاكًا.**
- **رقم الطلب:** `FR-YYYY-NNNNN`.
  - يتبع الاتفاقية الموحدة `PREFIX-YYYY-NNNNN` (التوظيف: `JOB-…`).
  - **يُولد في الخادم**، وفريد، وقابل للبحث، وبلا PII.
- **صفحة النجاح:**
  - "شكرًا لاهتمامك بالشراكة مع SHELTER COFFEE" + رقم الطلب + "سيخضع الطلب للمراجعة".
  - **بلا** مدة رد، ولا موافقة، ولا اجتماع، ولا حق امتياز.
- **الأمان:**
  - تحقق Server-side، وCSRF، وRate limit، وHoneypot.
  - حماية من XSS، واستعلامات بمعاملات (Parameterized)، وأخطاء عامة.
  - **لا CAPTCHA خارجي** بلا حاجة وموافقة.
- **التكرار:** تطابق بالهاتف والبريد واسم الشركة. عرض "طلبات سابقة"، **بلا دمج**.
