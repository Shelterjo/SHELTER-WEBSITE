## Naming Convention
`{Platform} - {Type} - {Name}` — أمثلة: `GA4 - Event - Menu View` · `GA4 - Event - Directions Click` · `GA4 - Config - Base`.
**Triggers:** `TRG - {Type} - {Name}` (مثال: `TRG - Click - Directions`) · **Variables:** `VAR - {Type} - {Name}`.
ممنوع: `Tag 1` · `New Tag` · `Test2`.
