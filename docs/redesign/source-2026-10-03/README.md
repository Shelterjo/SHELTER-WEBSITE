## ما تم سحبه

- نصوص الصفحات وعناوينها وMeta والروابط والعناوين الفرعية.
- 98 رابط صورة من نطاق الموقع نفسه، وتم تنزيل الصور الـ98 بنجاح، مع بصمات SHA-256.
- 104 ملاحظات سعر من صفحة المنيو؛ محفوظة كما ظهرت، وليست أسعارًا معتمدة بديلة.
- ملاحظات الخطوط والألوان من CSS العام. لا يُستنتج ترخيص الخط من وجوده على الموقع.
- لم تُرسل النماذج ولم تُسحب بيانات العملاء أو لوحة WordPress أو أسرار التتبع.
